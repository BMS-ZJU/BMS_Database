# 阅读体验维护指南

适用于网站字体、字号、标题层级、组件文字、阅读样式切换与屏幕／打印边界的调整。本指南保存可随仓库共享的约定及修改入口，使用仓库相对路径与公开链接。本机目录、预览地址、测试脚本及过程截图留在维护者的本地记录中，不作为阅读本指南的前提。后续确认新方案时更新对应条目，不连续追加多套现行规则。

## 调整原则

- 先结合实际页面判断问题来自字形、字号、密度、对比度还是组件层级，不把“费眼”直接等同于字号太小。
- 当前方案是继续微调的基线，不是不可修改的标准。一次优先比较少数相关因素，尽量固定页面、窗口、缩放和明暗主题，避免同时改动多项后无法判断原因。
- 标题与正文可以使用同一宋体家族，通过字号、字重及段前后留白建立层级。不要因为品牌要求加粗，就把所有标题一并加粗。
- 按内容角色维护共享样式；新增课程入口、练习链接、来源说明也应纳入已有规则，不为单个站外平台另建字号体系。页面正文不散落内联字体或字号覆盖。
- 评分与资料入口复用现行 `course-score`、`course-links` 等组件；旧占比表、资源表和彩色徽章样式已停用，不再恢复其类名和规则。
- 参考其他网站时可以比较排版方法，但以本站读者反馈为依据，不把某个网站或某次个人观感当作普遍结论。
- 宋黑搭配按阅读内容与操作文字分工，以完整内容块保持连贯；不因文字位于卡片或提示框内就统一换字体，也不把一块短说明逐行拆成不同字体。比较时明确字体家族、字重和字号分别改变了什么，并核对实际字形。
- 一次全宋体或宋黑搭配的个人观感不代表普遍最优。后续试验与已确认规则分开记录，确认后更新下方角色表。

## 当前方案

当前新版默认采用宋黑搭配，并保留原版／新版切换。后续按新的反馈更新这些规则。

### 字体角色

| 内容 | 当前字体 |
| --- | --- |
| 普通正文、来源说明、各级 Markdown 标题、评分说明及提示框内容 | 站内 `BMS Noto Serif SC`，中文、英文和数字采用该家族配套字形 |
| 已分类的试卷、小测正文 `.reading-paper`，包括答案与解析 | 英文和数字优先 `Times New Roman`，中文使用站内宋体；缺少 Times New Roman 时按字体栈回退 |
| 导航、搜索、按钮、筛选器、标签页及折叠开关 | 站内 `BMS Noto Sans SC`，中英数字使用该家族配套字形；常规字重 400，重点界面角色 500 |
| 课程入口卡片、资料目录卡片 | 标题及说明作为完整内容块使用站内宋体；资料卡片独立的阅读、打印、练习操作及状态标签使用界面黑体 |
| 课程目录、培养方案课程列表 | 整组界面黑体，课程名使用 500；列表外的章节标题、说明和培养方案解释段使用宋体 |
| 滚动页头的当前页名、页脚前后页的页面名称 | 站内宋体；“上一页／下一页”、版权及其他功能文字使用界面黑体 |
| 页头及手机侧栏的仓库链接 | 仓库名称、版本、Star 与 Fork 数字统一使用界面黑体；统计图标按数字基线对齐，仅作用于新版屏幕 |
| 页头和手机抽屉中的 BMS Database 品牌 | 独立的 `BMS Brand Serif`，字重 700 |
| 公式、代码 | 各自的 KaTeX 和等宽字体规则 |

`.reading-paper` 当前只自动识别 `courses/` 下，课程 `exams/`、`quizzes/` 中的直接资料正文页；分组目录、下载文件、普通主页和讨论课病例不在此范围。正文识别先于目录处理，资料正文末段即使也叫 `quizzes` 或 `exams`，仍应添加试卷类和打印入口。以后增加其他题目路径时，应明确检查分类逻辑，不能假设标题中带“题”就会自动适用。

新增入口需同时考虑容器和独立节点。例如首页 Ginkgo 使用独立 `.course-link`，应与 `.course-links` 内的入口共同遵循完整卡片宋体规则；卡片外的 `.course-source-note` 也按正文角色处理。资料目录的 `.resource-index-actions` 等操作行单独使用界面黑体，不把整个 `.course-resource-grid` 改成黑体。

正文标题与目录条目分开处理：`.course-catalog-group` 的章节标题保留宋体，内部 `.course-catalog` 使用黑体；`.curriculum-context`、`.curriculum-plan-summary` 作为解释内容整块保留宋体。`details > summary` 是展开控件，使用黑体；折叠后的阅读内容继续继承所在正文或试卷的字体。普通提示框的标题与内容保持宋体，不按边框外观判断字体角色。

### 字号与层级

| 参数 | 普通屏幕 | 窄屏 `max-width: 44.984375em` |
| --- | --- | --- |
| 正文字号 | `15.5px` | `15px` |
| 正文行高 | 继承主题 `1.6` | 继承主题 `1.6` |
| `--bms-reading-unit` | `19.375px` | `18.75px` |
| `--bms-reading-small-unit` | `20px` | `20px` |

顶部一级菜单 `.md-tabs__link` 在显示时固定为 `15px`；左右导航、搜索及其他界面的字号仍按各自规则维护，不联动放大。

正文不会因超宽屏主题根字号变大而再次放大。新版屏幕主标题 H1 统一使用所在正文的字体、500 字重、正文前景色和正常字距, 行高为 1.4; 字号继续沿用主题相对比例。普通章节 H2、H3 沿用主题字号、字重与留白, 桌面基线下 H1 约 31px、H2 约 24.22px、H3 约 19.38px, 不为飞跃手册另设章节字号。

新版 H1—H3 按可用宽度换行, 用 `text-wrap: balance` 改善多行标题的行长, 不支持时自然回退。保留普通单词断行规则, 仅当连续字符无法容纳时允许断开; 不以省略号、固定高度、强制单行或缩小整块正文塞入标题。完整文字、标题级别和锚点保持不变, 考试标题已有的学期分行及短资料名称整体仍按下方规则处理。带副标题的页首可局部收紧间距, 独立摘要块继续使用组件标题。原版与打印稿保留原有标题规则。

调整后检查长中文问句、中英混排、窄栏封面旁标题和考试多行标题, 覆盖桌面、手机、明暗与新旧模式; 同时检查标题下方正文、人物信息及入口卡片的换行和溢出。

组件使用 `calc(系数 * var(--bms-reading-unit, 1rem))` 或小字变量。后者让原本较小的辅助文字保留常规尺寸，不再随宽屏继续放大。根据文字角色和实际显示效果选择变量。保留 `1rem` 回退，布局间距、点击区域和根字号不随阅读字号一起缩放。

考试与小测正文的 H1 在屏幕上按“学年学期／课程名及资料名称”分行，字体、字号与文字内容沿用原有设置。`resource-export.js` 只为已识别的直接资料页中、以现有学年开头的标题包装 `.resource-title-term`，由屏幕 CSS 换行；未写学期时只分出学年，不推断学期，无学年前缀或已有自定义标题结构时保持原样。窄屏允许课程名继续自然换行，“期末回忆卷”等短资料名称通过 `.resource-title-kind` 保持完整，不强制整段标题不换行。保留单一 H1、原锚点、完整浏览器标题和导航名称；重复初始化不增加包装，独立打印／导出的标题继续原有排法。

### 局部文字的处理

- 培养方案说明中的强调文字和课程目录的展开／收起符号使用 `--md-typeset-a-color`。答案折叠条浅色沿用主题链接色，深色使用 `--md-default-fg-color`；检查对比度时合成折叠条的半透明背景与文字透明度，不只比较页面底色。该颜色规则适用于新旧两种阅读样式。
- 课程目录及培养方案的状态标签、目录分类统计在新版使用 `11px`；统计文字使用主题浅色前景，不再用更浅一级的颜色。课程名称仍沿用原阅读单位，重点界面字重为 500。
- 培养方案 `h5[id^="curriculum-"]` 使用 `0.95em`、常规前景色和既有粗体，约 `14.725px`／`14.25px`；标题中的学分标签仍作为辅助信息。其他页面的标题不因此整体加粗或放大。
- 连续答案和解析明确标记 `.answer-explanation`，新版为 `14px`、行高 `1.6`。优先为各解析段落添加 Markdown 属性列表，保留段落在原折叠区的位置，避免新增包装层改变原版和打印稿的首末段间距；不按字符数猜测解析，不整体放大 `details`、折叠标题或纯字母短答案。
- 需要持续阅读的长文字表格用 `.reading-table--prose` 包裹，新版为 `14px`，整张表的最小宽度为 `42em`，窄屏在表格区域内横向滚动。包装区域标明用途并可键盘聚焦；短数据表保持既有规则，不因行数多就使用此类。
- 以上局部覆盖只作用于新版屏幕阅读；原版和独立打印稿继续各自的规则。卡片、提示框和答案框仍按上方内容角色分配字体，不因调整字号而改变整个容器的字体。

卷首考试信息与资料说明分别作为完整内容块展示，避免同一条要求在信息栏和提示框重复。说明用语、分隔线和小测日期格式按[回忆卷指南的卷首说明](recall-papers.md#卷首说明的统一写法)维护，继续复用现有引用栏与提示框样式。

### 资料卡片的操作层级

- 考试与小测目录沿用 `.course-resource-grid` 响应式卡片，桌面两列、窄屏单列，不统一改为单列列表。标题字号使用 `0.72` 阅读单位，字重 650；标题下方保留阅读小链接及已有说明、标签和额外入口，卡片高度随实际内容自然变化，不补写占位说明。
- 资料标题承担主要阅读入口，标题下方同时保留“查看资料”或原有合集阅读小链接，作为可点击的操作说明。源码链接原样保留，无脚本仍能阅读。目录有至少一项站内试卷或小测时提供一个“打印 / 保存 PDF”入口，纯站外目录不提供打印入口。条目不生成逐项打印入口。
- 并列阅读、练习或版本链接之间保留旋转分隔竖线，复用 `.link-divider` 与 `.divider`：悬停或键盘进入时转一圈，颜色使用辅助前景色；只有一个链接不加竖线。重复初始化不累加。分隔线为装饰，不进入读屏或 Tab 顺序；遵循减少动态效果偏好。
- 同一条目的阅读、其他版本、原帖与站外练习链接由共用脚本归入同一操作行，不能依赖 Markdown 是否分段；兼容空白、普通中点和竖线分隔，统一替换为装饰分隔线，不能把仅含链接与分隔符的段落误作说明。DOM 与键盘顺序跟随显示顺序；重复初始化不增加打印工具或选择控件。目录不生成勾选控件；单一打印入口带入全部站内资料，默认只选第一份具体资料，选择区默认展开。答案位置及进一步的材料范围仍在独立打印预览调整；正文页保留一个“打印 / 保存 PDF”入口，默认只选第一份资料，预览选择区默认展开。打印入口常态使用辅助文字色，悬停和键盘聚焦时强调；样式限定在打印专用类，避免影响投稿表单复用的控件。

- 资料卡片的标题统一使用常规正文色和较明显的字重；说明使用较浅前景色及常规字重，练习等辅助操作也使用较浅前景色。链接悬停和键盘聚焦时使用链接色与明确反馈。是否带 Ginkgo 不改变标题的颜色层级，字体继续沿用内容和操作角色。普通正文中的资料与来源链接保留原有颜色。
- 样式集中在 `docs/assets/styles/resource-export.css`，以资料目录及其操作类限定作用范围。保留原课程名、站外、老师版等状态标签，Ginkgo 的统一 `.course-source-note` 放在条目组下方。阅读操作与打印范围见[回忆卷制作规范](recall-papers.md)；字体继续按上方内容和操作角色分工。

### 快速上手与页面帮助

- 首页「你想找什么」保留四张卡片，将「使用说明」改为第一张「快速上手」，直接链接到 `guide/#quick-start`；说明为「第一次来？了解怎样查找、阅读和保存资料。」。不另加常驻教程区块。
- 手机抽屉顶部也保留「快速上手」，独立于当前课程的目录层级，可直接查阅说明。入口在 `overrides/partials/nav.html`，位置和焦点样式在 `docs/assets/styles/styles.css`；检查嵌套目录和返回操作。
- 页头「帮助」负责当前页面的操作提示，与集中查阅的「快速上手」互补。默认提供使用说明页链接；脚本就绪后增强为开关。无脚本时仍可查看完整说明。
- 首次打开提供一行可关闭邀请，关闭或主动开启帮助后记住当前浏览器的选择；不自动开启说明模式。
- 开启后只给实际存在的课程筛选、资料分组、打印入口、材料标签及答案控件添加邻近短提示。来源、学年和存疑说明保持正常显示，原操作不被遮罩拦截。
- 搜索提示使用「页面顶部的搜索」等自然表述，不以图标外形代称功能。资料目录只在实际打印工具下方提示标题或查看链接阅读、进入预览选择打印范围，每页只显示一次，不逐条重复；没有目录打印工具时不显示该提示。
- 答案提示同时识别 `details.quiz-answer` 及现有「参考答案」「答案要点」「给分标准」折叠框，与导出脚本已有识别范围一致；只提示当前可见材料的首个答案，不把其他说明折叠框误当答案。材料标签提示按实际控件显示，不限于小测。
- 帮助开关在本标签页中延续；首次邀请用 localStorage 记忆，存储不可用时降级为本次浏览内记忆。关闭时移除提示与辅助关联，不残留额外间距。

### 两层标签与打印控件

资料切换复用 `pymdownx.tabbed` 生成的原生 `=== "..."` 标签、单选结构及主题交互。医学科学素养Ⅱ使用“类别 → 具体材料”两级标签：两个一级类别在手机上直接可见，二级保留普通标签字号和主题窄屏横向滚动，不把两类入口上下平铺成两套同级切换器。

培养方案沿用同一层级：年级为一级、班型为二级。年级较多时仍使用主题原生横向滚动，不强行挤入一行。层级样式限定在 `.resource-collection-marker + .tabbed-set` 与 `.curriculum-context + .tabbed-set` 的直属标签栏，仅一级字号为普通标签的约 1.15 倍，新版字重从 500 增至 600，原版保留主题 700 字重。一级各选项使用相同层级样式，选中状态仍由原生下划线和颜色表达；不缩放整个容器、标签正文或导出按钮。两级保留主题悬停和焦点样式，不另建胶囊按钮、卡片背景、分排指示线或字号计算脚本。调整后检查两级计算样式及实际截图，包含培养方案的年级／班型切换和局部锚点跳转；上述两处之外的标签不自动套用层级样式。

独立导出页的顶部工具栏只保留返回入口、已选／总份数、选择区开关、答案方式、打印按钮和“打印帮助”，摘要不重复完整资料标题。目录入口带入全部站内资料，正文入口带入本页资料；二者均默认只选第一份具体资料并展开选择区；合集可在预览中进一步细选，卡片不另设逐项打印入口。明确的整份或旧分组导出链接保留相应初始范围，已有默认首份的旧链接继续兼容。初次进入预览时选择区一律展开，包括单份、部分选择及空选。勾选后保持当前展开状态，由用户主动收起。开关沿用工具栏普通描边按钮，收起时显示“选择资料”，展开时显示“收起选择”。展开后先按原页面完整标题分组以区分学年、学期，再列出该页原有分类及复选框；不跨页面合并同名“小测 1”等选项。来源标题只拆分原文中明确的单个连续学年及紧随其后的学期、年级：名称为 14px、600 字重，下方时间信息为 12px 辅助灰字；不补写缺失信息，多个学年或无法可靠识别的标题保留完整原文。分类标题为 12px、600 字重和辅助灰色，具体资料保持 14px 常规字重；有分类的选项组向内缩进 8px，无分类的单份资料不增加缩进。宽屏短选项按原文顺序从左到右、从上到下排列为最多两列；按实际文字宽度识别的长选项占整行，侧栏变窄或文字放大到无法容纳双列时自然回到单列。选项最小高度为 32px、纵向间距为 2px；窄屏按内容自然占宽并换行，选项最小高度为 36px，保留清楚的勾选区域；全选靠左、计数靠右，计数使用 12px 辅助灰字；全选、数量和选项之间留出清楚的间距，不用提示框、图标或选中底色。阅读页保留页首“打印 / 保存 PDF”入口，具体范围、空选及更新状态规则统一见[回忆卷指南](recall-papers.md#打印范围与资源分页)。

选择区移出顶部工具栏：窗口至少 1200px 时使用约 300px 的左侧栏，资料列表与右侧预览各自滚动；收起选择后预览扩展。窄屏改为上下布局，选择区最高为视口的 30%，短屏收紧到 25%；只有资料列表滚动，全选、计数及顶部收起按钮保持可见。使用动态视口高度，保留列表和预览的键盘滚动入口，不用缩小字体或截断资料名称腾空间。

打印说明放进原生 `details` 的“打印帮助”，默认收起，展开内容限高并可滚动，不撑高工具栏；支持键盘开关及 Escape 收起。加载、空选和失败状态单独显示在工具栏附近，不折叠进帮助。屏幕布局使用独立滚动区域；打印媒体必须隐藏工具栏、状态、帮助与选择区，同时将布局和预览容器恢复为普通文档流，解除高度及溢出限制。调整时核对少量与大量资料下的预览高度、窄屏横向溢出及实际多页 PDF，不能只检查屏幕截图。

导出预览按资料分段，屏幕外的正文使用 `content-visibility: auto` 延迟排版与绘制，打印样式不使用该限制。资料准备分批让出主线程；只复制当前材料，避免重复处理整份合集。题图、公式及实际使用的公式字体仍须准备完成才能启用打印；题目高度与分页只在打印前测量，同一答案模式复用结果。调整时检查电脑和手机滚动、改选期间的取消、原生打印事件，以及未滚动到底直接导出的完整 PDF。

### 临时新旧切换

- 保留页头原版／新版切换，首次访问默认新版宋黑搭配，并记住选择。该按钮仍用于收集阅读体验反馈，尚无自动移除日期；将来改名或撤除时按新的反馈处理，不在其他维护中顺手移除。
- `html[data-reading-style="original"]` 使用原版正文与界面字体、字号及组件单位，包括原主题界面字体和顶部菜单字号；切换阅读样式不改变页眉图标、品牌字体或页面内容，明暗模式独立控制。
- 新版覆盖与变量仅在新版 `@media screen` 中启用。沿用 `:where(html:not([data-reading-style="original"]))` 等低优先级作用域，避免为了覆盖单个组件而提高全站选择器优先级。
- 偏好键为 `bms-reading-style:<站点根路径>`。保留首次默认新版、无效／禁用存储降级、跨标签页同步、键盘操作和 Material 即时导航下只挂载一个按钮的行为。
- 后续若撤除切换，应一起梳理模板脚本、数据属性、CSS 条件、变量回退和旧存储值，先明确旧选择如何迁移，避免只删按钮留下隐式旧模式。

### 字体资源与打印边界

正文宋体和界面黑体分别由 `docs/assets/fonts/noto-serif-sc/` 与 `docs/assets/fonts/noto-sans-sc/` 的站内 WOFF2 分片提供，使用独立别名、相对地址、`unicode-range`、可变字重和 `font-display: swap`。不依赖维护者本机恰好安装的字体，也不把 Noto 网页字体改回运行时 Google 请求。更新时分别维护 `README.txt`、`OFL.txt` 和 `SHA256SUMS.txt`，核对真实字形和授权来源；不要将 Windows 系统字体文件直接作为网页资产加入。宋体另含希腊字母与 `ⅠⅡⅢⅣⅤ` 的官方小分片；仅扩大 CSS 的范围而未核对文件中的字形，不能视为补齐。

字体名称字符串只说明 CSS 期望值，不能证明实际命中字形。需用浏览器字体检查确认宋体和黑体的中文、英数、希腊字母、课程名中的罗马数字及实际使用字重；新设备没有 Times New Roman 时应记录回退情况。原版不应主动请求正文或界面的 Noto 分片，但独立品牌字体仍可能加载；切换前已加载的字体可以留在浏览器缓存中。字体说明使用 `.txt`，避免位于 `docs/` 的 README 被构建为多余网站页面。

阅读变量只作用于屏幕。独立 `resource-export.html` 沿用自身 CSS、字体栈和 pt 字号，不加载阅读偏好脚本或自动接入正文、界面网页字体。`BMS Noto Serif SC`、`BMS Noto Sans SC`、打印栈中的 `Noto Serif CJK SC` 及品牌别名是不同的 CSS 家族。调整普通阅读体验时保持打印稿边界；需要改善打印时按实际授权另行修改并核验产物。

### 匹配题与表格

匹配题复用 `docs/assets/styles/resource-export.css` 中的 `.matching-group` 两栏结构，两侧独立编号并各自左对齐，继承所在网页或打印稿的正文字体与字号。电脑与打印稿为左右两栏，释义栏较宽、中间留出连线空白；长句自然换行，不使用数据表边框、表头底色或斑马纹。窄屏在同组内上下排列并显示“词语／待选释义”标签，不强迫横向滚动。结构、编号及分页边界见[回忆卷指南](recall-papers.md#匹配题)。

普通表格的独立导出样式限定在 `.resource-export-view .paper-content`，保留 `width: auto`、`max-width: 100%` 和 `table-layout: auto`。短表按内容收窄，左右自动外边距使整张表相对所在正文或题目缩进区域居中，保留上下间距与单元格对齐；宽表在可打印正文内自然换行，不裁字、省略或缩小字号。普通网页仍使用主题原生表格，导出不继承屏幕最小宽度或滚动容器限制，也不按当前窗口保存固定表宽。

`data-print-table="frequency"` 仅用于已明确要求同组等宽的短数据表。共享样式统一总宽、24 mm 首列、其余数据列均分，短数字和类别名称居中，并统一内边距、边框和表间距；不全站强制等宽列。普通新资料无需逐表标记，标记使用范围见[回忆卷指南](recall-papers.md#4-表格与附件)。

短编号的作答表可用 `.exam-response-table` 包裹，15 列采用等宽布局，屏幕总宽至少 `51em`，保证每格能容纳数字和三个字母。桌面使用正文可用宽度，窄屏在表格区域内横向滚动，不将作答格压缩成仅够放编号的宽度。独立导出按可打印正文宽度等分列，不继承屏幕最小宽度；保留全部编号、已有内容、空白格与填写空间，另行核查分页。普通表格继续使用原有规则，不把空白作答区域改判为回忆缺失。

## 页面身份与独立打开

浏览器标签页和收藏名称使用完整页面标题，与侧栏的短名称分开维护。`hooks/page_identity.py` 在构建时优先保留页面 YAML 的 `title`，缺省时使用正文 H1；课程资料标题缺少所属课程时，以课程主页已有名称补足。独立历史课程沿用自己的名称，不能因资料放在现行课程目录下就改判为同一门课。侧栏仍可写“课程主页”或简短学年。

修改后检查 HTML 的 `<title>`、单独打开和即时导航后的标签页名称，以及导出标题。不得从目录名猜学期、考试类型或来源；完整身份以现有课程名、正文标题和已核实元数据为限。

## 两侧导航与页内目录

- 左侧导航在所属课程和资料分组下使用简短名称，保留学年、已确认学期及原卷、回忆整理等必要区别，不重复上层已说明的课程名。正文标题仍保留完整名称。
- 右侧目录用于定位章节，试卷题型只保留名称及年份、A/B 卷、I/II 型等必要区分。分值、题量和选答说明留在正文，题型标题显示有依据的中文总分；分值计算、独立标签的语言及原有英文说明的保留边界，统一按[回忆卷指南的分值标注](recall-papers.md#分值标注)处理。使用 Markdown 的 `data-toc-label` 设置目录文字；修改标题时显式保留原有锚点，不只在桌面端用脚本删字。中文站点标题与导航保持原有语言。
- 长篇操作教程可按使用方式分别折叠，在外面保留适用情况，完整步骤和提示词按需展开。共同的收尾核对放在各方式的折叠框外，标题按内容关系归入所属流程；不因折叠而错误改变章节层级。页内目录保留方式入口，详细步骤在折叠内提供跳转；调整步骤标题时保留旧锚点及可访问的标题语义。长正文使用 `reading-details-body` 标记，按阅读单位跟随正文的桌面和手机字号；不只嵌套 `md-typeset`，以免恢复主题的固定字号，也不整段沿用短提示的小字号，并检查键盘操作、手机显示和旧链接直接展开。
- 试卷、小测合集的目录目标若位于未选中的标签页，点击或直接打开章节链接时沿目标的祖先路径展开全部内外层标签；共享行为在 `course-navigation.js` 维护。两层可各有一个可见选中项，未选类别保留其内部选择，但只显示当前材料正文；不改变培养方案的标签与目录筛选规则。
- 培养方案的班型标识以[课程名称与目录映射](../data/courses.yml)为准，同步维护 `data-curriculum-plan`、`curriculum-<年级>-<班型>-<章节>` 和映射中的 `curriculum_plans`。新目录与新链接使用当前标识；已发布的旧章节 ID 留在对应标题内的空 `<span id="旧ID" aria-hidden="true"></span>` 中作兼容别名，保留原值，避免替换成新 ID 后产生重复。
- 修改培养方案标识后，逐个检查年级和班型的标签选择、当前目录与标题前缀，以及新旧 ID 的唯一性和对应关系。跨班型直达是否展开目标标签须在新的浏览器上下文中实际验证，不能仅凭旧 ID 存在判定；保留既有标签与目录筛选逻辑。培养方案锚点直达、页内跳转、前进后退及即时导航重新渲染后，由 `course-navigation.js` 沿目标的祖先标签恢复年级与班型；旧章节别名定位到实际标题，提示框定位到自身，并避让固定页眉。手动切换标签不按旧 hash 强制切回。
- 调整后同时核对桌面右侧目录和手机页内目录，检查换行、跳转及无脚本时的目录文字；不靠固定行数裁切长名称。

### 资料使用说明与打印来源

- 资料使用标识由 `hooks/resource_usage.py` 写入构建后的资料正文，标题下仅保留短提示；考试与小测目录不添加页首提示，使用限制统一从全站页脚进入；补充的既有许可说明并入卷末来源首行，不再独占标题下一行。使用小字变量和主题颜色，打印入口与提示在空间足够时同排，窄屏自然换行并收紧间距；两者仍是独立节点，打印时只隐藏操作入口。默认中立说明与逐页启用的限制分开，具体范围见[回忆卷制作规范](recall-papers.md)
- 普通网页的卷末仅显示站名及原有许可说明，完整原文与使用限制网址在屏幕上隐藏，页首保留简短使用说明入口。完整地址仍在静态正文中，浏览器打印和独立导出预览继续显示；规则只匹配普通阅读页的屏幕样式，不隐藏独立导出中的来源地址。
- 全站页脚的“资料免费获取 · 使用限制”入口位于 `overrides/partials/copyright.html`，放在版权下方，与主题署名分别作为完整短句并列，手机按空间换行；不把资料限制附加到代码或独立许可资产
- 页脚的常用链接、使用说明和主题署名默认使用中性辅助文字色，悬停或键盘聚焦时才使用链接强调色；保留已有图文入口、44px 点击高度、明暗对比度与手机两列布局，不让辅助链接与正文资料争夺注意力。
- `.resource-use-notice` 和 `.resource-use-source` 的网页、独立导出样式集中在 `docs/assets/styles/resource-export.css`；导出使用自身 pt 字号，不引入阅读偏好
- 普通阅读页保留短提示及“使用限制”链接；独立打印预览和浏览器打印改为直接可读的文字说明，不要求纸面读者点击短链接。默认说明提醒保留原有署名、来源和使用说明，转载或重传前核对具体许可，并说明本站不提供商业使用授权；逐页启用的本站限制及原件独立限制分别沿用原文，不统一改成同一许可。完整正式网址仍在卷末保留，打印预览与实际纸稿使用同一份提示文字。
- 独立导出保留每份正文已有的标识和正式来源地址，答案集中卷末时来源说明排在答案之后。打印建议放在操作说明附近，打印时随工具栏隐藏；原文地址和使用限制属于正文，打印时保留
- 不使用覆盖正文的水印或依赖逐页重复页脚的方案；修改时核对电脑/手机、明暗主题、无脚本、即时导航和实际单份/批量 PDF，包含长标题、题图与三种答案模式

## 飞跃手册阅读布局

飞跃手册沿用全站宋黑字体、新旧阅读切换和明暗主题。`docs/assets/styles/feiyue.css` 只匹配 `.fly-handbook` 内的元素; 页面使用 `.fly-directory`、`.fly-interview`、`.fly-notes` 区分目录、访谈及说明, 不覆盖全站标题或其他课程组件。

- 总目录复用 `course-links` 和 `course-link`, 姓名与年级同排, 去向及研究方向合为一段说明; 尺寸、间距和交互直接沿用本站入口组件, 电脑双列、手机单列。人物入口整块可点击, 保留明确的键盘焦点; 不截断长学校名和研究方向, 不把未知去向补写成具体学校
- 页首保留文字简介, 不展示封面照片。使用说明保留必要的来源、年代及政策边界, 控制边框与底色的强调程度
- 访谈基本信息使用带字段名的定义列表, 短字段双列、长经历及多段信息跨列。字段名采用“年级与专业”“学位类型”等明确名称, 字段值及分项按原材料保留; 标签弱于内容, 无重复段落缩进或空白占位
- 手册完整封面放在阅读说明页, 桌面右侧180px, 窄屏居中180px; 保留原比例与封面大图入口。首页不放图片, 人物入口继续沿用紧凑的course-links; 摘要与声明页只显示简短名称, 标题锚点兼容原有地址
- 阅读说明用连续段落介绍项目, 保留有内容的小标题; 统计使用完整段落并明确样本范围, 维护流程留在外部项目记录。合并或更名标题时保留旧锚点
- 摘要独立成块, 与受访者问答区分, 保留紧凑的组件标题。新版目录、访谈和说明页的主标题与普通章节标题统一使用全站层级, 保留既有文字、顺序和锚点; 页名后有年份或采访类别时收紧两者间距。原版及浏览器打印保留原有标题样式
- 样式作为站点资源加载以支持即时导航, 实际选择器严格限定飞跃手册。调整后检查电脑/手机、明暗、新旧字体切换、键盘焦点和跨页跳转, 并核对全部保留原文、简历字段与链接。打印沿用现有浏览器打印, 不宣称提供独立导出功能

## 后续验证与记录

课程及普通页面底部的投稿操作由 `hooks/contribution_links.py` 提供当前页面定位，`overrides/partials/contribution-actions.html` 渲染投稿与直接编辑链接。`docs/contribute/submit.md` 的课程和页面联动选择由 `docs/assets/scripts/contribution-picker.js` 加载构建时生成的目录，可添加多个页面，分别在新标签页填写 GitHub 表单；仅打开表单不能标记为投稿成功。无脚本或目录加载失败时保留原生 GitHub 表单入口。`docs/assets/styles/contribution.css` 负责间距、键盘焦点与打印隐藏，操作区采用界面字体。修改时核对当前页选择、跨课程切换清空旧页面、手机换行、键盘访问、即时导航与资料打印排除，不修改课程正文。

页底参与入口默认收起为“完善本页”，使用原生 `details/summary`，展开后提供补充资料、纠错和直接编辑三个原有链接。该辅助操作使用主题次要前景色和普通展开箭头，不套用提示框边框、底色、图标或阴影；悬停使用链接色，键盘焦点保持明显。仅调整这一操作区，正文资料链接继续保留原有颜色。最外层保留 `.contribution-actions`，确保浏览器打印隐藏与独立导出排除仍生效；检查无脚本开合、收起后的键盘顺序、手机触控、明暗与新旧阅读模式。

投稿下拉使用可输入筛选的 combobox：按名称、代码、标题或学年匹配，必须从候选列表选定，任意输入不作为目标。保留原生选择值供页面绑定；支持方向键、Enter、Escape 和中文输入法，列表按可用空间向上或向下展开。搜索框复用课程目录的 `course-catalog-search-row`，填写和查看入口复用 `resource-page-tools`，添加另一页复用 `resource-batch-toolbar`。页面选择组用普通分隔线，不另设卡片或实色主按钮；仅多页时显示移除。相关验证包含无匹配、未选定状态、组合输入、触摸、键盘焦点及明暗模式。

按实际改动选择检查范围，不每轮重复全量构建和截图。纯说明或局部文字记录只核对文字与链接；修改样式、结构或交互时，在最终候选上集中构建与检查。

- 字体／字号：选择有普通段落、各级标题、评分或提示框的主页，以及课程目录、资源目录和试卷正文；检查正文、完整卡片、操作行、辅助文字、独立入口和按钮是否各自命中预期字体及字重。新资源还需核对分类、长答案和长文字表格的语义标记，不因路径或组件相似就假设已适配。
- 适配：检查电脑、手机和明暗主题；改字号变量时补查宽屏，涉及页头时补查窄屏。关注行长、断行、层级、点击区域和横向溢出，不只比计算字号。
- 开关／模板：核对新旧两种模式、首次访问、刷新与跨页记忆；改相关交互时补查键盘、存储失效、跨标签同步和真实即时导航。原版应与本轮开始时的原版基线比较。
- 共享导出样式：确认入口与原有站外练习链接仍可用，页面打印媒体不随阅读偏好变化。按[回忆卷指南的代表样本](recall-papers.md#构建与代表样本)检查实际涉及的范围选择和 PDF；表格改动抽查短表、长文本表、题目列表内表格与频数表，以相同 A4、页边距和缩放核对宽窄窗口下的居中、溢出及分页。匹配题抽查短、长释义组和手机显示；是否扩大验证，按[贡献指南的本地验证原则](../CONTRIBUTING.md#本地验证)判断。
- 即时导航：本地预览的 sitemap 若仍带公网根路径或端口，可能退回整页跳转；刷新后偏好保留不能证明即时导航正确。按实际站点路径验证，测试中的地址映射不要带入业务实现。
- 评论区：样式目录在页面脚本首次执行时解析为绝对地址，持久保留的主题监听使用该地址，不随即时导航后的页面深度重新解析。检查跨不同目录深度往返后切换明暗主题，确认样式仍指向站点的 `assets/styles/` 目录，且没有重复绑定监听。

环境准备与构建方法见 [README.md](../README.md) 和 [贡献指南](../CONTRIBUTING.md)。在当前工作树使用已安装项目依赖的 Python 运行严格构建；如需输出到仓库外，用 `--site-dir` 指定维护者自行选择的预览目录。构建产物不纳入提交。发布前核对范围内差异，发布后分别核对 Actions、Pages 和线上实际文件／显示；合并成功不等于网站已更新。

新试验先复用适合的当前候选和预览入口，旧稿只留作历史。每次记录调整的因素、确认采用的方案，以及实际验证边界；更新本指南的当前条目。交接只保留状态和入口，不把截图、浏览器脚本或固定进程号复制成长期规则。
