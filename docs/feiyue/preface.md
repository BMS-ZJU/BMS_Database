## 这本手册记录什么 {#_2}

<span id="_3"></span>基础医学的同学很难系统了解前辈的毕业去向、接触科研的经历，以及升学选择背后的考虑。许多经验散落在聊天、群文件和个人记忆中，这本手册通过采访，将这些经验整理成可供后来者查阅的记录。

关于手册与网站的缘起、整理过程和未完成的设想，可以阅读何冠辰的[《项目后记》](../about/project-afterword.md)。

<span id="_4"></span>本册主要记录受访者的个人经历与体会，通过不同的访谈呈现多种选择。项目组不把个别路径包装成统一教程，也不替读者作决定。

### 一册、一库、一传承 {#_5}

访谈汇编成“一册”，采访原件与授权记录构成“一库”，后续团队持续补访、纠错和更新，形成“一传承”。课程资料、新生手册和本科实验室轮转资料由 BMS Database 网站承载。

## 这本手册怎样使用 {#_6}

### 按受访者阅读 {#_7}

可以先阅读与自己年级、研究兴趣或升学计划接近的访谈，再比较不同受访者作出选择的理由。这些经验来自受访者当时的处境，需要结合自己的情况参考。——“大学里，你才是决定未来的第一推动力。”

### 区分访谈与政策 {#_8}

访谈可以说明规则如何影响个人。涉及报名、转段、推免、直博和 4+1 项目的具体要求时，应查阅当年官方文件，并核对具体情况。——“我们专业也在越变越好哦！”

### 保留原话与不确定性 {#_9}

手册保留采访中的问答，以及受访者的弯路和真实感受。“未知”表示访谈资料未明确提供该项信息。
