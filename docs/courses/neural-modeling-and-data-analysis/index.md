# 神经建模与数据分析

这门课主要讲怎样用数学模型描述神经元和神经网络的活动，以及怎样分析神经信号、提取其中的信息，也会接触一些基础的机器学习方法。整体以经典模型和成熟方法为主，适合用来打下神经建模与数据分析的基础。

## 课程学习内容

现有课件与实验材料涉及以下几部分：

??? note "展开查看较详细的课程内容"

    - **神经元与突触建模：**离子电流、扩散与能斯特电位，膜的等效电路，整合放电模型、Hodgkin–Huxley 模型，以及树突、突触和抑制作用。
    - **神经信号与数据分析：**动作电位串、时间序列、神经编码与解码，脑信号与脑机接口，频谱分析和主成分分析。
    - **神经网络与机器学习：**速率模型、线性回归、前馈神经网络与感知机，以及循环神经网络和神经群体的时间动态。

## 上课与平时任务

2025-2026 学年秋冬学期每周两次课，一次 2 学时、一次 3 学时，大致对应一次理论课和一次实验课。

平时作业是使用 MATLAB 完成教师布置的一系列任务，并撰写实验报告。实验主题包括：

??? note "展开查看实验主题"

    - **Practical 1：**MATLAB 入门、矩阵运算与绘图。
    - **Practical 2：**一维扩散、等效电路与能斯特电位。
    - **Practical 3：**LIF 模型参数估计、Hodgkin–Huxley 模型及不应期。
    - **Practical 4：**突触的胞体抑制与树突抑制。
    - **Practical 5：**神经元对刺激的响应，Raster、PSTH、调谐曲线与线性回归。
    - **Practical 6：**脑机接口与脑信号分析，包括频谱、脑电、P300、SSVEP 与运动想象。
    - **Practical 7：**从线性回归到感知机和多层感知机。
    - **Practical 8：**循环神经网络与 LSTM。
