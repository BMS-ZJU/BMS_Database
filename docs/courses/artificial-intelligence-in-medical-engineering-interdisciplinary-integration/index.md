# 医工交叉融合中的人工智能

这门课把人工智能的基本思路放进医学场景，通过配置开发环境、运行开源项目、微调模型和完成文献综述，接触医工交叉中的实际问题。

## 课程学习内容

课程从人工智能算法思想、机器学习基础和医学数据处理入手，再通过医学影像、文献检索等任务练习实际应用。目前收集到的课件和实验材料主要覆盖前半程。

??? note "展开查看较详细的课程内容"

    - **人工智能与机器学习基础：**智能目标、不同算法的思路与可解释性，向量空间、梯度下降、过拟合与欠拟合，以及大小模型的配合。
    - **医学数据与多模态模型：**医学数据收集与处理、隐私保护和脱敏，Transformer 与大语言模型、预训练与微调，以及多模态模型在医学影像中的应用。
    - **开发环境与开源项目：**配置 Python 开发环境，运行舌苔识别项目，本地部署多模态模型，使用牙科全景片进行推理和微调。
    - **文献检索：**根据研究问题选择数据库和检索方法，设计检索式、获取文献并评价检索结果。

开课时的后续安排还包括 AI 辅助文献阅读与综述、提示词与智能体，以及小动物运动轨迹和精细行为分析。这些部分的实际课件尚未收齐。

## 上课与平时任务

**2025-2026 学年秋冬学期：**每周一次课，每次连续三课时。按当年的修读记录，通常是两课时理论、一课时实验。

实验需要记录操作过程和结果，并完成相应报告。环境部署和模型实验会要求保留运行截图、解释代码或配置、记录遇到的问题及处理过程；文献检索报告则要交代选题、数据库、检索式、检索结果，并介绍一篇重要文献。

??? note "展开查看已有实验材料中的任务"

    - **环境部署：**了解计算机硬件配置，安装和配置操作系统、Python 环境及开发工具，并验证环境是否可用。
    - **舌苔识别开源项目：**运行与分析代码，练习训练和识别，记录模型文件位置、显存占用、报错处理及功能探索。
    - **多模态模型部署与微调：**本地部署 Qwen2.5-VL，进行多图推理，将数据整理为指定格式后使用 LLaMA-Factory 微调模型。
    - **文献检索：**从膝骨关节炎的精准分型、精准治疗、功能康复中选择一个方向，在 Web of Science、PubMed 等数据库检索医工交叉与人工智能相关文献。

**2026-2027 学年秋冬学期：**实践项目占 45%，通常由 2—3 人组队完成，包括随堂实验与自主探究、中期汇报和综合大作业。

2025-2026、2026-2027 学年均规定：缺课一次扣 1 分，扣完为止；缺课达到课程的三分之一及以上不能参加考试。2025-2026 学年从考勤分中扣除，2026-2027 学年的扣分归属尚不明确。

## 学习建议 { #_6 }

按 2025-2026 学年秋冬学期的修读经验，这门课事情比较多，但给分还可以，也能学到不少东西。想多接触一些工程实践的同学可以考虑；也有同学觉得，课上教的一些内容靠 AI 自学也能学会，收获感会因人而异。

环境配置可能花不少时间。个人实验记录中遇到过 Python 解释器、依赖版本和 GPU 支持方面的问题，安装和运行时可以先核对这些设置，并随手记录报错与处理过程。实验数据、报告和环境配置也建议及时备份。
