# 法医学

课程介绍法医学各分支的基本概念，并结合案例讲解损伤、死亡、物证和临床鉴定等问题。现有课件涉及法医病理学、毒理学、生物学、临床学等内容。

## 课程学习内容

??? note "展开查看较详细的课程内容"

    - **死亡与法医病理：**死亡与尸体现象、机械性损伤、猝死和机械性窒息。
    - **毒物与物证：**法医毒理学，以及个人识别、亲权鉴定等法医生物学内容。
    - **法医临床与精神医学：**活体损伤、伤残与劳动能力等鉴定问题；课表另列法医精神病学。

## 上课与平时任务

2022-2023 学年夏学期面向全校本科生的课表安排 8 周线下教学，每周 3 学时。另有两项线上学习：机械性损伤（大话法医学）和交通损伤（法医病理学），各 3 学时。

导论课件要求完成中国大学 MOOC 作业，并提交至学在浙大。课堂点名计入该年课件所列的平时成绩。

## 期末考试

2022-2023 学年夏学期课件只明确期末为笔试，没有说明开闭卷规则。

来源及学年未核实的旧修读记录列出单选、名词解释、简答和案例分析四种题型。

## 学习与选课建议

一份来源和学年未核实的旧修读记录提到，平时任务不多，不同领域教师讲授的概念和案例很有意思，认真听课能有收获。

这份经历中，期末考查较细，复习需要认真看 PPT，尤其要记住概念性内容。原作者觉得给分较严格，个人考试结果也不理想。

## 课程信息

- **学分：**1.5 学分。
- **预修要求：**病理学（[疾病基础](../../mandatory/the_basis_for_human_diseases/index.md)）、解剖学与组织学（[人体结构与功能学](../../mandatory/structure_and_function_of_the_human_body/index.md)）、药理学（[基础药理学](../../mandatory/basic_pharmacology/index.md)）。
- **授课语言：**2022-2023 学年夏学期课表标为全英文。
- **教材用法：**2022-2023 年导论课件建议以教师 PPT 作为教材，课前或课后在学在浙大提供；书本作为参考。参考书包括《法医学》第 6 版、《法医学概论》第 5 版。
