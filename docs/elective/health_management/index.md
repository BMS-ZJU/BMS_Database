# 卫生事业管理

## 2023-2024 学年记录

- **学分：** 1.5 学分；
- **主讲教师：** 周旭东；
- **考核方式：** 一次开卷考试。

最后一次课会说明考试方向。当年给出的方向是宫颈癌与 HPV，学生需要课后自行查找资料，并结合课堂内容准备。回忆者记得考试可能只有一道类似论述或作文的题目，但已经无法回忆具体题干。

## 学习建议

这门课适合对卫生事业管理和公共卫生政策感兴趣的同学。准备开卷考试时，不能只堆积材料；可以围绕教师给出的方向，提前整理问题背景、课程中的分析框架、关键证据和自己的论证顺序，确保考试时能够快速找到并组织内容。

## 往届经验

**Chams（2023-2024 学年）**给出的个人推荐度为 3/5，认为周旭东老师讲课尚可，但自己对主题兴趣不高。该评价只反映个人兴趣，不代表课程质量的统一结论。
