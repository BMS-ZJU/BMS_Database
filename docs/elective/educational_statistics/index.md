# 教育统计学

教育统计学主要讲统计方法在教育研究中的应用，从数据整理与统计推断，到常用检验、回归和多变量分析。课程通过课堂展示与讨论、期末作业进行考核。

## 课程学习内容

现有课堂讲义围绕数据描述、假设检验和教育研究中的统计分析展开，配有 SPSS 操作示例，也涉及 AMOS 和 PROCESS。

??? note "展开查看较详细的课程内容"

    - **统计概念与数据整理：**描述统计与推论统计，统计图表，集中与离散趋势，自由度、正态分布，以及假设检验的思路和步骤。
    - **常用检验与分析：**单样本、配对样本和独立样本均值检验，单因素与重复测量方差分析，相关分析、线性回归和卡方检验。
    - **多变量分析：**探索性与验证性因子分析、中介效应分析，以及相应的软件操作和结果解释。

## 上课与平时任务

课堂展示要求如下：

- 阅读 1—2 篇量化研究论文，以教育、心理领域近 5 年的研究为主；
- 阐述论文采用的研究方法和统计方法，也可以谈学习这门课的收获、困惑或问题；
- 每组 1—2 人，制作 PPT，展示约 5 分钟；
- 预计在第 7—8 周展示。

到课检查按学年区分：

- **2024-2025 学年：**曾有几次纸质签到，由学生依次签名。
- **2025-2026 学年：**点人回答问题，并按名单点名。

2025-2026 学年的通知还说明，期末作业在第 4—5 周布置。

## 期末作业

2024-2025 学年夏学期的期末作业包括以下两部分。

### 统计软件分析

约占期末作业成绩的 70%。选择 4—6 种统计方法，完成软件操作、结果报告与解释，并讨论这些方法在教育研究中的应用。

- 结果以规范图表为主，配合文字描述，并解释软件输出。
- 可将创业教育设为自变量，创业知识和创业能力设为中介变量，创业意向设为因变量。
- 其他方法需要的数据，可根据数据类型自行设定。
- 字数建议不超过 3000 字。

### 问题图谱或导图

约占期末作业成绩的 30%。根据自己的理解整理课程内容，可交电子版，也可手绘后拍照转为电子版。
