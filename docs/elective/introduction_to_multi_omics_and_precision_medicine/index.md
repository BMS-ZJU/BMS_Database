# 组学与精准医学前沿导论

组学与精准医学前沿导论
• 整体评价：硬核，事少分不高
• 最大难点：
• 全英教学：全英文PPT和需要适应的口语（但是可以锻炼英语！）
• 教学内容：
• 涉及组学概念，组学数据库，临床应用（如基因治疗）等，前期偏基础，后期有很多硬核前沿技术原理介绍，非常干货。老师备课非常认真，每节课PPT都有100多页。如果问他们科研问题也能得到大佬指导。(≧∇≦)/
• 分数构成：
• 日常讨论占 40%，作业占 20%，结业论文占 40%，无期末考。
• 十六节课中有四次左右的小测。最后几次小测较难且老师会限时或者在学在浙大上传的PPT中去掉答案，只让来教室的同学们答对。（为防智云，有答案的那张PPT会过得非常快）
• 考勤情况：
• 笔头签字。不喜欢代签，会口头警告。
• 重点课业：
• 一次全英pre，四人小组共40min，四个人都要讲，讲给定的一篇文献，分为introduction（1人） ，results（2人）和discussion（1人）。最后老师会英文提问每个人。一般都是问些简单问题，技术原理、为什么会有某某结果和为什么采用这个技术。好好准备相关技术尤其是与课上内容重合的部分，可以全部答上来。（我们组pre时我一个人答了所有人的问题（）
• 一篇期末全英论文，2000-3000词，要求至少十篇引用和两个图表。topic在他们给的7个中选一个即可。
• 给分：
• 非常求是（不过我们是第一次开课）。占0.4的全英pre给分很狠，瞄到均分都是70多80多（全程念稿情况下）（虽然大多数人都是这样，老师们也仍然给这个分）。我每节课都积极和老师互动，最后论文也写的特别认真，引了50篇文献，又请老师帮忙修改。私下问老师时他们都跟我说放心你成绩肯定不错。(>﹏<)就这样才卡绩4.5。（当然因为课程硬核的缘故我不后悔。）但是追求绩点的可能不推荐来。
