# 疾病基础

课程内容分为病理学和病理生理学两部分：病理学侧重疾病的形态变化，病理生理学侧重疾病发生发展中的功能与代谢变化。

## 课程内容与安排

2025-2026 学年共进行了五次线上限时小测。冬学期另有一次病理学切片与大体标本小测。该小测在讲课后于实验课教室进行，有两次作答机会，题目不变但顺序可能变化，提交后可以查看答案；目前不能确认它计入哪一部分成绩。

病理学实验即读片课，共六次。每次围绕相应章节，由教师讲解病理学知识，并带领学生观察数字化切片和大体标本。课后需要在形态学数字化教学平台找到指定材料，截图、标注并完成实验报告。

病理生理学实验共一次，主题是缺氧与酸中毒对家兔呼吸系统和循环系统功能的影响。实验包括家兔麻醉和固定、颈部手术、动脉与气管插管，随后改变吸入气体或酸碱状态，记录呼吸、血压和血气等指标，并在课后提交实验报告。

理论课有时会点名回答问题，并记录被点到但未到场的同学。但分数构成没有单列考勤分，因此不能确定缺席记录是否影响总评。

## 学习建议

**病理学和病理生理学都要准备。** 两部分在期末试题中都占有较大比重，专业英文名词也需要提前熟悉，否则英文题目会增加理解难度。

**尽量在平时跟上进度。** 课程内容多，期末考查也比较细，不适合到期末才第一次系统学习。复习时仍应以课程内容为主，不能把速刷小测和历年卷当成完整替代；往年选择题很少原样重复，即使考查相近内容，也可能更换题干或改用英文。

**病理学实验课尽量按时参加。** 读片和观察大体标本需要教师带领，缺课后仅靠自己在平台寻找和辨认材料难度较大。往年诊断题会给出大体图和切片图，部分图片可能在实验课看过，或者能在实验课 PPT 中找到。期末图片题所占分值不低，复习时可以把实验报告中的典型大体标本、切片、病名和形态特点放在一起整理。
