# 疾病基础

课程内容分为病理学和病理生理学两部分。

## 课程学习内容

课程从疾病发生发展的基本机制开始，学习细胞和组织损伤、炎症、循环障碍、肿瘤等基本病理过程，再进入各器官系统疾病的形态变化与功能障碍。

??? note "展开查看较详细的课程内容"

    - **疾病发生的基础：**疾病概论、分子机制、细胞功能与信号转导异常，以及大数据库资源与应用。
    - **基本病理变化：**细胞和组织的适应、损伤与修复，血液循环障碍、炎症、肿瘤的一般特点及其病因和发病机制。
    - **功能与代谢紊乱：**发热、缺氧、水电解质和酸碱平衡紊乱、凝血与抗凝血平衡紊乱、休克、缺血再灌注损伤和应激。
    - **各系统疾病：**心血管、呼吸、消化、泌尿、淋巴造血、生殖、神经和内分泌系统的病理变化，以及心、肺、肝、肾功能不全和糖脂代谢紊乱。

## 上课与平时任务

以下是2025-2026学年秋冬学期的安排。

### 理论课与小测

理论课有时会点名回答问题，并记录被点到但未到场的同学。但分数构成没有单列考勤分，因此不能确定缺席记录是否影响总评。

当年共进行了五次线上限时小测。冬学期另有一次病理学切片与大体标本小测。该小测在讲课后于实验课教室进行，有两次作答机会，题目不变但顺序可能变化，提交后可以查看答案；目前不能确认它计入哪一部分成绩。

### 病理学实验

病理学实验即读片课，共六次。每次围绕相应章节，由教师讲解病理学知识，并带领学生观察数字化切片和大体标本。课后需要在形态学数字化教学平台找到指定材料，截图、标注并完成实验报告。

### 病理生理学实验

病理生理学实验共一次，主题是缺氧与酸中毒对家兔呼吸系统和循环系统功能的影响。实验包括家兔麻醉和固定、颈部手术、动脉与气管插管，随后改变吸入气体或酸碱状态，记录呼吸、血压和血气等指标，并在课后提交实验报告。

## 期末考试

2025-2026学年期末为闭卷考试，中英文均有。本站收录的2023-2024至2025-2026三学年回忆卷，都包含选择题、问答题和病理诊断或病例图片分析。

2025-2026学年的问答题还考到了家兔实验中的处理，以及呼吸、血压等指标变化的机制。

## 学习建议

**病理学和病理生理学都要准备。** 可以先系统梳理病理生理学，理解疾病的发病机制和各系统的功能变化，再学习病理学的形态特征。专业英文名词也需要提前熟悉，否则英文题目会增加理解难度。

如果觉得课件或课堂内容太抽象，可以先看 B 站相关章节的讲解，对该章有个大致了解，再回到本课程的 PPT 和录播课。准备病例选择题时，也建议大致记住常见指标的正常范围。

**尽量在平时跟上进度。** 课程内容多，期末考查也比较细，不适合到期末才第一次系统学习。复习时仍应以课程内容为主，不能把速刷小测和历年卷当成完整替代。2025-2026学年的备考复盘提到，选择题很少原样重复，即使考查相近内容，也可能更换题干或改用英文。

**病理学实验课尽量按时参加。** 读片和观察大体标本需要教师带领，缺课后仅靠自己在平台寻找和辨认材料难度较大。往年诊断题会给出大体图和切片图，部分图片可能在实验课看过，或者能在实验课 PPT 中找到。期末图片题所占分值不低，复习时可以把实验报告中的典型大体标本、切片、病名和形态特点放在一起整理；课件中分散的内容，也可以用表格或思维导图梳理。

这门课内容繁多，没什么补天的好办法，能做的只是刷刷卷子、看看课件。如果你期末才看到这条，重视绩点的话，还是考虑缓考吧。
