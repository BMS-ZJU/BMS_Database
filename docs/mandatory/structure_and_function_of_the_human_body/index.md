## 课程介绍

- 本课程为《系统解剖学》、《组织学与胚胎学》、《生理学》三门课程的整合课程。

- <b> 整合式教学 </b>：宏观结构 + 微观结构 + 宏观与微观功能

- 课程由几位老师共同讲授。每个系统分为解剖学、组织学和生理学三个部分。几位老师的水平不必多说，基础医学专业专业课唯一真神。

- 期末考试为闭卷笔试，解剖学组织学和生理学均有涉及，其中生理学占较大比例，据多位同学反馈需记忆内容多，难度较大。

课程要求较三门单独的课程低，但记忆的内容仍然很多，好在期末考试仅涉及夏学期的内容，压力相对来说小一点。建议平时的课即使不听，最后也要抽出时间看一遍智云，并仔细看一次三本书对应部分的内容。
