# 医学科学素养Ⅰ

!!! warning "26级同学请留意开课时间变化"

    本页根据24级及之前的课程经验整理。26级起，这门课由大一春学期调整至大一冬学期。提前开设是否会影响课程内容，目前尚不清楚，请26级同学谨慎参考。

这门课围绕生物医学的重要发现及其应用展开，通过理论课和小组展示了解 DNA 双螺旋、限制性内切酶、人类基因组、干细胞等主题。往年也讲过 Warburg effect、质谱仪等内容。

## 上课与平时任务

以下为2023-2024、2024-2025学年的安排：线下理论课与讨论课相结合，使用中文和英文。每周1次课，每次2学时，通常两次课完成一个主题，第一次由教师讲解，第二次分组讨论和汇报。

每次讨论课重新分组。PPT可能要求使用英文，口头展示可以使用中文，并尽量脱稿；具体语言要求以当次任务为准。

## 学习建议

准备展示主要靠自己查资料、整理内容，不能只依赖理论课。如果是智创班同学，这可能是第一次做课堂展示，可以先翻看往年智云，了解大致流程。

每次都会重新分组，尽早分清任务和截止时间很重要。组长要合理分配任务，审核组员提交的内容，留出时间统一结构、安排衔接，检查英文术语和PPT表达。不要把未经审核的AI输出直接拼到一起。
