# 第二次讨论课：心血管药理

## 讨论课说明

原课件以张先生的疾病进展为主线，依次讨论高血压与血脂异常、心绞痛与心肌梗死，以及射血分数降低型心力衰竭。本页按课件顺序保留病例、讨论问题和课件中明确给出的补充要点。原始课件体积较大，本站不提供下载。

### 课堂流程

1. 课前复习心血管药理相关内容，并自行组成 3～4 人小组。
2. 每次案例导入时，由一名同学朗读病例。
3. 每人提取并记录患者信息，3～5 分钟后由老师抽取同学讲解。
4. 小组围绕教师给出的问题讨论并回答。
5. 记录纸在课后签名提交，按完整性、逻辑性和条理性评分。

## 第一阶段：高血压与血脂异常

### 病例

张先生，55 岁，文职人员。5 年前体检发现血压 155/100 mmHg，经检查未见肝肾功能、心功能异常，诊断为原发性高血压。医生给予氨氯地平治疗，但患者担心长期服药及药物不良反应，仅在自认为血压升高时服药。

近 2 个月反复出现搏动性额部头痛，偶有轻微胸闷。就诊时血压 150/95 mmHg，心率 80 次/分。实验室检查如下：

| 指标 | 检查结果 | 参考范围 |
| --- | ---: | ---: |
| 总胆固醇 | 5.79 mmol/L | 2.84～5.69 mmol/L |
| 甘油三酯 | 0.72 mmol/L | 0.56～1.70 mmol/L |
| HDL | 2.38 mmol/L | 1.05～2.20 mmol/L |
| LDL | 3.18 mmol/L | 1.55～3.36 mmol/L |

颈动脉超声显示双侧颈总动脉斑块。

### 讨论问题

1. 张先生的抗高血压治疗过程是否存在问题？具体是什么问题？
2. 氨氯地平降低血压的作用机制是什么？该药是否适合张先生？
3. 下一步应增加剂量、换药，还是联合其他抗高血压药物？还有哪些常用抗高血压药？
4. 患者是否需要进行调血脂治疗？如果需要，可以选择什么药？
5. 结合阿托伐他汀可能引起的不良反应，列出三项用药注意事项。

### 原课件整理要点

- 课件认为钙通道阻滞药可通过扩张血管降低血压和心脏后负荷，同时扩张冠状动脉、增加肾血流；使用时需注意水肿、头痛、头晕和心悸等不良反应。
- 课件以阿托伐他汀为例说明他汀类药物：通过抑制 HMG-CoA 还原酶、增加肝细胞 LDL 受体表达，促进 LDL 摄取与代谢，并减少 VLDL 合成和释放。
- 课件列出的阿托伐他汀用药注意点包括肝功能损伤、肌病、与 CYP3A4 抑制剂或底物合用时的药物相互作用、新发糖尿病、胃肠道反应和特殊人群用药。

## 第二阶段：心绞痛、心肌梗死与心律失常

### 病例进展

此后 5 年，张先生规律服用氢氯噻嗪、氨氯地平和阿托伐他汀，血压维持在约 135/85 mmHg。

本次因突发胸前区疼痛入院，休息及舌下含服硝酸甘油后未缓解。此前一个月内，患者慢跑或剧烈游泳时会出现钝性胸部不适，休息 5～10 分钟后可消失。

入院时血压 145/90 mmHg，心率 80 次/分，心电图显示 ST 段抬高，诊断为急性心肌梗死。冠状动脉造影发现前降支堵塞 99%，置入 2 枚支架。住院期间一度发生心房颤动，静脉使用胺碘酮后恢复窦性心律。

出院后用药包括：

- 美托洛尔
- 沙库巴曲缬沙坦
- 单硝酸异山梨酯
- 阿司匹林
- 氯吡格雷

### 讨论问题

1. 一个月内活动时出现的胸部不适，与本次突发且不能缓解的胸痛有何区别？
2. 硝酸甘油为何采用舌下含服？其作用机制是什么？
3. 胺碘酮终止房颤的作用机制是什么？该药具有哪些药理作用？
4. 如果长期使用胺碘酮，需要注意哪些问题？
5. 如何向患者解释每一种出院药物的使用目的？

### 原课件整理要点

- 舌下含服硝酸甘油可避免肝脏首过效应并快速起效，适合心绞痛急性发作；单硝酸异山梨酯起效较慢、作用时间较长，更适合长期预防。
- 课件将出院药物的主要用途概括为：美托洛尔属于 β 受体阻断药；沙库巴曲缬沙坦同时作用于血管紧张素受体和脑啡肽酶；单硝酸异山梨酯属于硝酸酯类；阿司匹林通过抑制 COX 发挥抗血小板作用；氯吡格雷通过阻断 P2Y12 受体发挥抗血小板作用。
- 原课件只列出了胺碘酮相关讨论问题，没有在对应页面给出完整答案，因此本页不另行补写。

## 第三阶段：射血分数降低型心力衰竭

### 病例进展

又经过 15 年，张先生一直定期检查并规律服药。近期长时间工作时出现呼吸急促，并伴足部和踝部水肿、疲劳加重。平卧时轻度呼吸困难，坐起后好转。

查体发现：心率 100 次/分、节律规则，血压 165/100 mmHg，颈静脉压升高，足踝部 3+ 水肿。空腹血糖 7.8 mmol/L，血钾 4.1 mmol/L。超声心动图显示心脏扩大、收缩不良，左心室射血分数约 30%。诊断为 C 期射血分数降低型心力衰竭。

出院后用药包括美托洛尔、沙库巴曲缬沙坦、阿司匹林、氢氯噻嗪和达格列净。

### 讨论问题

1. 心力衰竭患者存在哪些代偿机制？
2. 针对血流动力学改变，可以使用哪些抗心力衰竭药物？
3. 针对 RAAS 激活，可以使用哪些药物？它们分别靶向什么分子，具有哪些药理作用？
4. 针对交感神经系统激活，可以使用哪些药物？它们分别靶向什么分子？
5. 针对神经激素变化，可以使用哪些药物？它们分别靶向什么分子？
6. 患者如何从美托洛尔、沙库巴曲缬沙坦和达格列净中获益？
7. 使用氢氯噻嗪时需要注意哪些问题？

### 原课件整理要点

- 心输出量下降后，交感神经系统和 RAAS 激活，可引起血管收缩、水钠潴留、心脏重构和心力衰竭进展。课件据此串联了利尿药、扩血管药、强心药、ACEI、ARB、盐皮质激素受体拮抗药和 β 受体阻断药。
- 课件指出，美托洛尔长期使用可拮抗过度交感激活、减慢心率、降低心肌耗氧量，并抑制心脏肥大和重构；开始使用时则需留意短期血流动力学变化。
- 沙库巴曲缬沙坦由脑啡肽酶抑制与 ARB 两部分组成。单独抑制脑啡肽酶可能伴随血管紧张素Ⅱ升高，因此课件强调联合阻断 RAAS 的设计思路。
- 达格列净通过抑制肾近端小管 SGLT2，减少葡萄糖和钠的重吸收。课件将排糖、排钠和渗透性利尿列为其可能使射血分数降低型心力衰竭患者获益的相关作用。
- 氢氯噻嗪使用时需注意低钾、低镁、低钠等电解质紊乱，以及高血糖、高脂血症、高尿酸血症、脱水所致肾血流下降、胰岛素抵抗和皮肤反应等问题。

## 沙库巴曲缬沙坦研发补充

原课件最后用较多篇幅介绍了沙库巴曲缬沙坦的研发过程，主要脉络如下：

1. 早期单用脑啡肽酶抑制剂未达到预期效果；同时抑制 ACE 和脑啡肽酶的 Omapatrilat 又因血管性水肿风险和疗效优势不足而终止开发。
2. 后续方案将脑啡肽酶抑制剂沙库巴曲与 ARB 缬沙坦组合，形成血管紧张素受体脑啡肽酶抑制剂（ARNI）。
3. 课件引用 PARADIGM-HF 研究说明其临床证据：8442 例射血分数降低型心力衰竭患者接受沙库巴曲缬沙坦或依那普利治疗，中位随访 27 个月后，研究因沙库巴曲缬沙坦组获益明显而提前终止。
4. 课件还以该药的共晶形式为例，说明固定比例复方在成分均匀性、释放同步性、稳定性和专利布局方面可能优于简单物理混合。
