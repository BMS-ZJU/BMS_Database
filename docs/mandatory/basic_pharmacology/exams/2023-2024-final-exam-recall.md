3. 支气管扩张药有哪些种类？分别举出代表药物。

4. 大环内酯类与氨基糖苷类药物作用机制的异同。

5. 吗啡在脊髓背角抑制疼痛的分子机制。

6. 新斯的明的临床应用等。
