# 2025-2026 学年春夏学期基础药理学期末回忆卷

!!! info "回忆卷说明"

    本页依据考后回忆整理，不提供参考答案。选择题仅记录考查方向；简答题和病例分析题按现有回忆列出。

---

## 一、单项选择题（40 分） {: .exam-section .exam-section--choice }

*共 40 题，每题 1 分。现有回忆仅记录以下考查方向：*

- 新斯的明、酚妥拉明；
- 利尿药与作用部位的对应；
- 各类药物的药理作用和效应；
- 反映生物利用度的 3 个指标；
- 抗铜绿假单胞菌药物；
- 环丙沙星耐药原因；
- 8 岁儿童检出蛲虫时，阿苯达唑和甲苯达唑能否使用；
- 噻嗪类药物的临床应用，选项涉及尿崩症、高血压伴心衰、胰岛素抵抗；
- 氨基糖苷类不抗厌氧菌的原因；
- 一道机制涉及 `vTK` 的药物题；
- 术前注射阿托品的作用。

!!! info "原记录"

    `vTK` 为原记录中的写法，具体术语无法确认。

## 二、简答题 {: .exam-section .exam-section--short }

*共回忆到 9 题，每题 5 分。*

1. 毛果芸香碱降低眼压的机制、药理作用，以及除治疗青光眼以外的临床应用。

2. 丙米嗪的药理作用、临床应用和药物分类。

3. 抗肿瘤药物的种类及代表药物。

4. 调血脂药物的分类及代表药物。

5. 药代动力学与 ADME 的解释。

6. 阿司匹林的作用机制、药理作用和不良反应。

7. 强心苷的益处及原理。

8. 地高辛的作用机制和不良反应；糖皮质激素的作用机制。

9. 质子泵抑制剂的机制、原理和代表药物。

## 三、病例分析题 {: .exam-section .exam-section--analysis }

*共回忆到 3 个考查方向：*

1. 氯丙嗪的药理作用。

2. 左旋多巴的不良反应。

3. 抗生素使用病例：

    1. 使用一种抗菌药效果不佳，提示其不抗支原体；要求选择合适药物并解释两种药物的机制。
    2. 进一步制定联合用药方案，涉及 β-内酰胺酶、抗生素改造方向，以及为什么感染控制前不能大量使用糖皮质激素。
