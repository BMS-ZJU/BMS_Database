# 基础医学科学研究技能Ⅱ

这门课主要学习大型科研仪器的原理和使用，了解仪器如何产生数据，以及如何处理和呈现数据。课程既有理论学习和排定的上机课，也需要自行参加仪器培训、预约使用并提交书面材料。

## 课程内容与安排

课程围绕细胞流式、共聚焦显微镜、病理实践和蛋白纯化四部分展开，每部分各有一次理论课和一次上机实践，共四次理论课、四次上机实习课。上机实践按分组在医学院公共技术平台进行，课后在学在浙大完成章节测试。

课程后段还安排原始实验数据获取、数据整理、论文撰写和答疑，课下继续收集和整理数据。每次课都要纸质签到，有时老师还会数人数。

### 仪器学习与自主使用

排定课程之外，还需自主参加两次仪器使用学习，并完成两次仪器预约。课上的上机实践与课下自主使用是两项任务。

参加仪器学习和预约使用，需要在仪器设备共享服务平台管理系统注册账号并挂名课题组。没有可挂名课题组，或实验室不支持时，可以挂在任课老师名下预约。课程要求提供本人名下的预约记录。

自主仪器使用也可以使用所在课题组的自有设备，并提交相应使用证明。

### 书面报告

根据实习的实验内容写总结，说明仪器用途、产生数据的形式、对应仪器国产化情况的简单调研，以及个人收获和课程建议。报告分为实验报告、国产化思考、课程建议与意见三部分。

报告形式自由，在课程结束时提交电子版。两个学年的篇幅要求不同：

- **2025-2026 学年：**约 1000 字，需有图和图注。
- **2024-2025 学年：**约 2000 字。

## 学习建议

**培训和预约尽早安排。** 仪器学习班虽然很多, 但和自己的时间或想学习的有时很难对上，建议尽早完成, 不要拖到课程结束前才集中完成。
