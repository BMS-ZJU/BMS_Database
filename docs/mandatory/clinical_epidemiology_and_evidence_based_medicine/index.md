# 临床流行病学与循证医学

这门课涉及 Meta 分析、决策树和一些统计学概念，与后续基础医学科研有联系。课程由多位教师分部分讲授。

## 学习建议

这门课内容多，背诵量也大。不同教师对相近知识点可能讲得不一样，复习时要留意各部分课件的说法。有同学觉得给分不太好，但如果背诵能力较强、知识点记得熟，拿高分也会比较容易。

复习可以先用钉钉群里的知识总结梳理重点，再回到各位教师的 PPT。汇总材料没有覆盖所有内容，PPT 中还有散落但可能考到的知识点。

时间实在紧张，可以结合历年回忆题抓反复出现的考点；想准备得更充分，再花时间把各部分课件中的知识点尽量背全。
