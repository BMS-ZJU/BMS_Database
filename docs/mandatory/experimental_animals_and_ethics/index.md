# 实验动物与伦理学

课程分为实验动物学和实验医学伦理学两部分，主要讲常用实验动物、疾病模型和相关研究技术，以及动物福利、动物实验伦理和医学研究伦理。

## 课程学习内容

实验动物学部分围绕实验动物的选择、质量控制、饲养环境和研究应用展开，伦理学部分讨论如何对待实验动物，以及医学研究中的伦理问题。

??? note "展开查看较详细的课程内容"

    - **实验动物基础与质量控制：**实验动物的定义、分类、命名，以及遗传和微生物质量控制。
    - **常用模式动物与疾病模型：**小鼠、大鼠、豚鼠、果蝇、线虫、斑马鱼和爪蟾等动物的特点及研究应用，疾病模型的分类、建立和选择。
    - **相关研究技术：**转基因与基因编辑技术，以及医学影像和神经活动成像技术。
    - **饲养环境与实验安全：**环境因素、饲养设施与管理、生物安全和动物实验安全管理。
    - **动物福利与伦理：**动物福利、动物实验伦理原则，以及医学研究与应用中的伦理问题。

## 上课与平时任务

课程每周两次课，每次 2 学时。往年很少点名，但到课人数较少时可能点名，是否计分不清楚。

学期末有一次小组展示，可能要求每位组员都上台。老师通常在学期末通过同学发放 PPT，供考前复习。

## 分数构成

2024-2025、2025-2026 两学年均未公布实际采用的计分方案。大纲中的平时 20%、期末 80% 仅供参考，考勤和小组展示的具体计分方式也未明确。

## 期末考试

期末为闭卷考试，题型包括判断题、单项选择题、简答题和论述题。

## 学习建议

课堂基本是照着 PPT 讲，以应试为目的，平时不必专门跟课学习，可以把主要复习放在考前。点名和学期末的小组展示仍需留意。

### 考前复习

期末有一定难度，内容几乎都来自 PPT，但课件多，选择题和判断题考得细，不能只看大标题。常用模式动物的特点、适用实验和相关实验技术尤其值得认真复习。

时间比较紧时，先把 PPT 完整过一遍，边看边筛选需要集中复习的内容，再根据整理出的笔记记忆。如果希望准备得更充分，还需要注意名称和其他细节。

历年回忆卷有助于了解题型和出题方向。往年大题有不少相近内容。
