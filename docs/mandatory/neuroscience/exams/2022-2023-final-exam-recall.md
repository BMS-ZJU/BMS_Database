# 2022-2023 学年春夏学期神经科学期末回忆卷

> **2 道必答题、12 选 6 道选答题**  

!!! info "回忆卷说明"

    本页依据考后回忆整理，不提供参考答案；题图未收录，涉及图形的数据按文字回忆保留。

---

## 一、必答题（2 题） {: .exam-section .exam-section--analysis }

1. 说明树突整合的定义、分类、机制和影响因素。

2. 给出膜片钳控制不同电压时 AChR 电流随时间变化图（I = 0 时 V = 0，呈正比例关系），完成下列各问：

    （1）作 I-U 图；

    （2）计算电导；

    （3）计算平衡电位；

    （4）已知 E<sub>K</sub> = −80 mV、E<sub>Na</sub> = +50 mV，计算 g<sub>K</sub>/g<sub>Na</sub>。

## 二、选答题（12 选 6） {: .exam-section .exam-section--short }

1. 哪种胶质细胞会影响 K<sup>+</sup> 浓度？说明其机制。

2. 说明大脑皮层各分叶的功能。

3. R 蛋白（题目中给出的假设蛋白）可促进 Delta 信号增强，说明其对神经干细胞发育的影响。

4. 说明味觉传导的概念，并按三种方式分类。

5. 说明外侧膝状体（LGN）的信息传递机制。

6. 为什么需要睡眠？

7. 列举三种生物节律并举例。

8. 说明情绪、情感的定位，并选择其中一种展开论述。

9. 除 LTP、LTD 外，列举几种突触可塑性。

10. 运动控制系统由哪些部分组成？各部分有什么作用？

11. 说明在人类演化研究中设定人类与黑猩猩共同祖先的重要意义。

12. 写出五种膜片钳记录方式的名称；列举行为学实验：3 种空间导航实验、1 种恐惧实验和 1 种社交实验。
