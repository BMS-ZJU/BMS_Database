# 感染与免疫学

课程内容即免疫学、病原微生物学和寄生虫学，理论课之外还有实验、线上小测和小组讨论展示。近三学年的回忆卷都对专业英文有直接要求，既要读懂题目，还需要拼写术语并用英文解释或作答。

## 上课与平时任务

2025-2026 学年秋冬学期的现有记录包括：

| 环节 | 数量 | 记录中的形式 |
| --- | ---: | --- |
| 线上小测 | 3 次 | 选择题 |
| 免疫学实验 | 3 次 | 实验 |
| 病原微生物学实验 | 2 次 | 实验 |
| 小组讨论展示 | 5 次 | 小组展示 |
| 期末考试 | 1 次 | 题型见下方 |

目前没有可靠的完整分数比例。

## 近年期末考试

三份回忆卷显示，题型框架大体相近，但题量、选答规则和每题分值会变化：

| 学年 | 回忆记录 |
| --- | --- |
| 2023-2024 | 8 道选择题、8 道名词解释、5 选 4 问答题、1 道论述题 |
| 2024-2025 | 16 道选择题、10 选 8 名词解释、8 选 4 简答题、1 道论述题 |
| 2025-2026 | 16 道选择题、10 选 8 名词解释、10 选 4 简答题、1 道论述题 |

选择题和名词解释连续三学年都有全英文记录；英文问答题需要用英文作答。2024-2025 和 2025-2026 学年的简答题还要求至少选择一道英文题。历年卷适合用来认识题型和检查遗漏，不能当作下一学年的固定范围。

## 学习建议

**专业英文不能只停留在认识。** 免疫学术语、病原微生物名称和常见机制需要能拼写，也要练习用英文解释。等到考试时再把中文答案临场翻译，风险比较大。

**复习范围不要只剩几个大框架。** 有往届同学遇到过大题从课堂细节中出题的情况，漏掉一个知识点就会损失较多分数。准备常见重点的同时，也要用课件和小测检查自己是否遗漏具体概念。

**时间有限时，可以先把免疫学准备扎实。** 2025-2026 学年的一份经验认为，免疫学和病原微生物学是主要部分，免疫学的名词解释、英文拼写和问答值得优先投入；微生物与寄生虫的关键概念仍要保留。这只是该学年的复习取舍，不表示其他内容不会考。
