# 医学科学英语基础

医学科学英语基础主要讲医学专业词汇，以及文献阅读、科研论文写作与学术汇报。

## 课程学习内容

医学英语部分围绕词根词缀和专业术语展开，另一部分讲文献阅读、论文写作与学术交流。

??? note "展开查看较详细的课程内容"

    - **医学英语词汇：**词根、前缀、后缀及连接形式，发音与词形变化，以及细胞、组织、器官生理和疾病治疗相关术语。
    - **文献阅读：**文献查阅、检索方法与阅读技巧。
    - **科研论文写作：**论文的组织结构、行文逻辑与发表。
    - **学术汇报：**报告技巧与分组汇报实践。

## 上课与平时任务

课程以线下理论课为主。张岩老师讲授第一节导论，之后主要由高洋老师授课，包括三次基础医学英语讲授，以及文献阅读、科研写作与报告技巧，最后安排分组汇报。

约在第五次课组队，每组 2—3 人，教师为每组分配一篇英文文献。每位学生据此完成个人英文摘要，小组再围绕同一篇文献制作全英文 PPT、进行全英文汇报。汇报时可以使用演讲者视图或手机提词，并未明确要求完全脱稿。

## 期末考试

期末为全英文闭卷考试，主要考医学术语和词根词缀。近几年几乎所有题都来自 *Medical Terminology: An Illustrated Guide* 的教材练习，具体复习章节会在教师 PPT 中标出。

题型包括选择、连线、填空、反义词和组词，对应教材的 pretest、review 等部分。往年材料对题量与分值的记录并不完全一致，具体安排以当年通知为准。

## 学习建议

**以准备考试为主的话，平时可以自己看教材。** 词汇课基本是老师照着 PPT 念，不一定要跟着听；自己按 PPT 标出的范围看教材、记词根词缀和做题，也可以完成复习。文献阅读与写作部分和期末考试的直接关系不大。

**摘要和展示一起准备。** 两项任务合计占 60%，要按要求完成。个人摘要和小组展示使用同一篇文献，可以放在一起准备；有三人小组利用一个周末完成的经验。

### 期末复习

**近几年的期末很适合围绕教材习题补天。** 有同学主要靠背题拿到高分，准备快的同学甚至有考前一晚复习后拿到期末几乎满分的经历。不过，这是近几年的经验，以后题目可能不再直接出自课本，仍要先确认当年的考试范围和要求。

**能提前一周开始，就别把记忆全压到最后一晚。** 每天花约一小时，逐渐熟悉和记忆，考前再集中冲刺，记忆效果会比临时突击好一些。复习可以按下面的顺序进行：

1. **先熟记 PPT 里的词根词缀。** 对应教材主要是黄色方框内的内容。配套单词要能认出来，也可以通过词根词缀的组合推断含义；蓝色方框里的很多单词会在课后题中出现，不必把全部蓝框单词单独背一遍，可以面向习题学习。
2. **再做教材课后题。** 重点看 review 中单词与含义匹配的连线题，以及用给定词根词缀组成新词的填空题，也要看 pretest 选择题。书末的 Answer Key 可以用来核对答案，再覆盖其他已知题型。
3. **把形近、容易混淆的词根词缀放在一起比较。** 既能强化记忆，也要能在题目中区分它们的含义，不能只记住一个模糊的印象。

复习重点只占教材相关内容的一部分，不用因为没背完整本书而过分焦虑。时间紧时先抓常见词根词缀和习题，不必一开始就硬背所有长难术语；具体考查范围仍以当年要求为准。速通资料没有收齐全部内容，有余力时再对照教材补漏。
