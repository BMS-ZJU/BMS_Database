# 2023-2024 学年秋学期医学科学素养Ⅱ期末回忆卷

!!! info "回忆卷说明"

    本页依据考后回忆整理，不提供参考答案。选择题与判断题有缺失；文末观点为回忆者个人备注，不作为题目或答案。

---

## 一、选择题（20 × 2 分） {: .exam-section .exam-section--choice }

1. 第一、第三四分位数之间的区间叫什么？

2. 衣服颜色、地区等数据属于什么数据？

3. `-1, 1, 2, 3, 100` 这一组数据属于左偏还是右偏分布等。

4. 描述数据集中趋势的指标中，哪一个受极值和偏移影响较大？

5. PDB 对什么物质的三维结构进行建模？

6. 第一类错误指什么？

7. 样本均值的 95% 置信区间表示什么？

8. 哪些因素决定置信限（limit of confidence）？

9. 根据一份 R 语言检验输出，判断使用的是配对或独立样本 t 检验、单尾或双尾检验。

10. 已知一个样本的均值和方差，求包含总体中 95% 个体的区间；原回忆特别提示这与置信区间不同。

11. 辨析 `dnorm`、`pnorm` 等 R 函数的输出。

12. 暴露组与非暴露组发病比例之比叫什么？

13. 根据男女两组体重数据判断应使用哪一种检验。

14. 承上题，计算或判断自由度。

15. 承上题，根据结果判断是否接受假设。

16. 关于 PubMed 的叙述，选择正确的一项。

## 三、计算题（共 50 分） {: .exam-section .exam-section--analysis }

1. **5 分：** 给出核电站周围唐氏综合征病例数和某州出生缺陷中唐氏综合征病例数，判断核电站是否对周围有影响。

2. **5 分：** 给出总体方差、样本均值和样本方差，判断样本均值是否显著高于期望值。

3. **15 分：** 对一个 2 × 2 表进行卡方检验：求自由度与各格期望频数，计算卡方值并作出结论。

4. **10 分：** 根据线性拟合的 R `summary()` 输出写出拟合方程；由决定系数（coefficient of determination）计算相关系数（correlation coefficient）。

5. **15 分：** 根据独立双样本 t 检验数据表选择检验方式、确定自由度、计算 t 值并作出结论。

!!! info "回忆者备注"

    - 关于第 1 题，回忆者表示未确认考点，并猜测可能涉及泊松分布；这一判断不是原题信息。
    - 关于第 3 题，回忆者算得的期望频数不是整数，因此提醒复习时留意此类计算的处理方式。
