# 医学科学素养Ⅱ

课程分为生物医学信息和生物统计两部分。前几次课学习文献与数据库检索，之后转入概率统计、研究设计和 R 语言实践。文献检索部分主要使用中文，其余练习和试题全部使用英文。

## 课程内容与安排

生物医学信息部分包括中英文数据库、PubMed、MeSH、Web of Science，以及围绕科学问题开展检索和获取文献全文。生物统计部分包括描述性统计与数据图形、概率与常见概率分布、敏感度与特异度、贝叶斯法则、区间估计和假设检验、配对与两样本检验、方差分析、相关与回归、卡方检验和非参数检验，并穿插使用 R 进行数据整理、作图和统计分析。R 语言属于授课与实践内容，但现有期末考试不考查 R 语言操作。不同班次的具体范围可能有所调整。

2025-2026 秋学期的 23 级班次包括三次线上计分小测、两次线下计分小测，以及不计分的课堂练习。线上小测均为 60 分钟、两次机会；线下小测为纸质大题。各次开放时间、补测记录和题目见[练习与小测](quizzes/index.md)。

2025-2026 夏学期的 25 级班次同样由小测和期末考试构成，小测包括纸质和线上编程两种形式；目前没有足够信息确认具体次数和先后安排。

## 学习建议

**先熟悉概率统计常用的英文术语。** 期末的概率统计题使用英文，阅读障碍会直接影响对题目和统计方法的理解。平时看课件、练习和历年资料时，可以同步整理中英文对应。

**统计复习不能只记计算结果。** 需要知道有哪些统计方法、各自适用于什么条件，并熟悉选择方法、列出计算步骤和书写结论的完整过程。这部分的题型较公式化，现有练习和小测覆盖面较完整，可以用来熟悉英文表述和计算题格式。

**文献检索和生物统计的复习力度可以有所区分。** 文献检索考查较少、难度也相对低，至少应浏览一遍课件；期末复习的主要时间更适合放在生物统计部分。

**不要错过计分小测。** 线上小测开放后应尽早完成，避免平台故障或错过时间；计分的线下小测需要按时到场。课堂上还可能出现不计分的纸质练习，不要把两类任务混在一起。

**没有跟上统计课时，可以额外自学。** 课程中讲授的概率统计部分可能较为难懂，概率论与数理统计教材或网络课程可以帮助补足概念和计算方法，但仍要回到本课程的英文课件、练习和答题方式。
