# 缓考

缓考获批后，可以申请参加后续学期相同课程的期末考试。办理时有两步：先申请这一次考试缓考，再在准备参加考试的学期申请“缓考考试”。

??? info "后续学期的含义"

    这里的“后续学期”，指以后再次开设这门课的某个学期。例如，现在是春夏学期，可以选择：

    - 接下来的秋冬学期，前提是秋冬也开设相同课程；
    - 下一学年的春夏学期；
    - 更晚一些、再次开设这门课的那个学期。

    具体选择哪个学期，要关注课程后续的开设情况，也要考虑自己的修读和毕业安排

## 哪些情况可以申请

学校的[本科课程成绩评定与管理办法](https://meetc.zju.edu.cn/2024/0306/c79045a2885825/page.htm)列明了三类情形：

- 因病住院或急诊留院观察，能够提供校医院证明；
- 本人或直系亲属遇到不可抗拒的突发事件，导致本人不能在校，能够提供有效证明；
- 代表学校参加学术、交流、比赛等活动，能够提供组织单位的证明。

从实际办理经验看，因病申请有一定灵活性。也有同学因为复习不足、状态不好，甚至单纯不想参加当次考试而尝试申请缓考。这种想暂时缓一缓的需求确实存在，但“单纯不想考试”并不是学校列明的申请事由；能否获批，仍要看真实情况、证明材料和审核结果。

如果焦虑、失眠、呕吐等不适已经影响到参加考试，可以就诊时如实说明，由医生评估并出具相应材料。如果只是想逃避眼前的考试，则不建议把缓考当作常规选择：考试和复习任务仍然在，推迟后还可能与其他课程的安排叠在一起。

## 申请缓考

以下结合本科生院[2026年4月30日公布的办理流程](https://zdbk.zju.edu.cn/jwglxt/xtgl/xwck_ckLoginNews.html?xwbh=50AA96418C25E042E0632AB3CA0AB796)和实际办理经验整理。因病申请推荐走校医院线上审核，下面按这条路径展开，并在对应环节补充线下办理方式。

### 1. 考前提交申请

进入[本科教学管理信息服务平台](https://zdbk.zju.edu.cn)，打开“考试管理 → 课程缓考与缓考考试申请 → 课程缓考申请”，选择课程并填写原因。

**要在开考前发起申请，并继续跟进审核结果。** 开考后突遇紧急情况，及时联系所在学院教学科或学园辅导员处理。

### 2. 准备证明，完成相应审核

**因病申请：先就诊、取得证明**

下面分别介绍紫金港校医院内科、肠道科的就诊经历。挂哪个科室应结合实际不适，拿不准时可以先问导诊；检查项目和能否开具证明由医生结合病情判断。

**到内科就诊**

1. **挂号并到诊区候诊。**挂紫金港校医院的内科号，到内科诊区等待叫号。内科就诊的同学可能较多，要给候诊、检查、取结果和盖章留出时间。
2. **说明身体状况和缓考需求。**向医生说清具体不适，例如实际出现的焦虑、呕吐、失眠，以及症状持续多久、怎样影响日常生活和参加考试。同时说明近期有考试，希望评估是否需要休息、开具病假证明以申请缓考。把真实感受说清楚即可，不必自己先下诊断。如果医生认为需要进一步评估心理方面的问题，可能会建议转到心理科；这样可能增加挂号、就诊和评估的环节，病假证明也未必能在内科当场办完。可以当场问清去哪里就诊、需要带什么材料、后续由哪个科室评估并开具证明，给转诊留出时间。焦虑、失眠等实际困扰仍应如实说明。
3. **完成医生安排的检查。**血常规、转氨酶等抽血检查，流程相对简单。按医院指引完成检查后等待结果。如果医生还安排心脏超声等检查，担心费用时，可以先问清检查目的、必要性、预计费用，以及是否有合适的其他安排，再与医生商量。
4. **拿到结果后再找医生。**血常规有约20分钟出结果的情况，其他项目可能更慢。结果出来后带回给医生，结合检查结果继续说明当前状况及缓考需求。
5. **由医生评估是否开病假单。**医生会根据病情判断是否需要休息、休息多久。由于开具缓考医生需要承担一定责任，实际办理中也可能遇到医生不予开具证明的情况，可以问清原因和后续需要做什么；有腹泻等相关不适、需要其他科室评估的，也可以咨询是否转诊。

**到肠道科就诊**

肠道科获得病假单相对简单一点，如果有腹泻等相关不适，也有同学在肠道科就诊后办理病假证明，过程与内科略有不同：

1. **先登记，再就诊。**到肠道科后先按现场要求登记，向医生如实说明腹泻等不适及缓考需求。
2. **按要求检查和采样。**除了血常规，还需要另做采样。当时的采样体验类似肛拭子，具体项目名称未核实，实际检查以医生安排为准。
3. **等待结果并返回医生处。**约半小时拿到结果；实际等待时间可能不同。拿到结果后交给医生，由医生结合情况评估是否需要休息和开具病假证明。

**拿到病假单后**

1. **核对休息期限。**医生可以开具1—3天病假单，具体天数取决于病情和医生判断。留意病假单上的日期能否覆盖需要缓考的考试。
2. **到前台盖章。**拿到病假单后，还要办理相应盖章。周末前台不值班、需要工作日再去盖章；如果考试就在周末前后，提前确认窗口安排，给这一步留出时间。
3. **收好后续要用的材料。**保留门诊病历、门诊诊断证明、盖章病假单和检查结果。盖章材料可以拍清楚留存，接下来在线上申请休假时上传，纸质材料继续保留用于后续审核。

**推荐：校医院线上审核**

取得材料后，在“浙大钉 → 工作台 → 校园数字医疗 → 申请休假”中填写信息、上传材料并提交。提交后留意审核状态和补材料要求。

等校医院审核通过，再进入教务系统“考试管理 → 课程缓考与缓考考试申请 → 课程缓考申请 → 已申请信息”，打印缓考申请表，用于后续院系审核。

**校医院线下审核**

如果选择线下审核，需要先从教务系统“课程缓考申请 → 已申请信息”打印缓考申请表，再带齐材料去校医院2号楼308室防保科审核。之后携带这份已审核的申请表及相关证明，继续办理院系审核。

**因突发事件或学校活动申请**

突发事件按要求提供有效证明；代表学校参加活动的，提供组织单位证明。联系所在学院教学科或学园辅导员，说明具体情况并跟进材料要求。

### 3. 院系审核

准备好缓考申请表及相关证明后，按本人所在学院或学园办理签字、盖章。**校医院审核无论走线上还是线下，都需要完成这一步。**

- **医学院学生：**到医学院综合楼601办理签字、盖章。
- **蓝田学园或竺可桢学院学生：**联系自己的辅导员办理签字、盖章。

### 4. 本科生院窗口审核

带好缓考申请表、盖章病假单及相关证明，去纳米楼办事大厅办理。出发前检查申请表上的校医院审核信息、院系签字和公章是否齐全。

1. **到大厅门口先取号，**按现场提示选择对应业务。
2. 在相应窗口附近等候，留意叫号。
3. 叫到自己的号码后，到窗口提交申请表、病假单及所需证明；如有缺项，按工作人员说明补齐。
4. 交件后继续查看教务系统中的审批结果，确认缓考申请已办结。

因事申请的同学携带对应的事由证明，无需准备病假材料。流程咨询可联系本科生院教务处学籍中心：**0571-88208655**。

## 后续参加考试

准备参加考试的学期，先查询是否开设相同课程，再到“考试管理 → 课程缓考与缓考考试申请 → 缓考考试申请”办理。具体开放时间和截止日期以当期教务通知及系统提示为准。

提前确认考试时间，并与接收缓考的任课教师沟通。若课程停开、课程号变化，或考试安排与其他课程冲突，应及时联系学院教学科处理，不要等到临近毕业时才核对剩余学分。

## 平时分和最终成绩

按[本科课程成绩评定与管理办法第二十三条](https://meetc.zju.edu.cn/2024/0306/c79045a2885825/page.htm)，后续学期接收缓考的任课教师可以采用期末考试成绩，也可以结合平时成绩评定总评；同一课程的缓考学生须采用一致的评定方式。

因此，申请参加后续考试时，要提前问清楚是否采用原平时分、需要完成哪些平时环节。**缓考后再次跟班上课，也可以与老师沟通放弃之前的平时分，按新的修读情况重新取得平时分。**希望重新跟班修读、重新取得平时分的，应在开始修读前与任课教师和学院确认具体安排。

缓考后还可以选择学校统一安排的补考，但参加补考后，成绩会标注“补考”。按[该办法第十二条及第二十五条](https://meetc.zju.edu.cn/2024/0306/c79045a2885825/page.htm)，实际参加补考后的结果按及格或不及格记载：

- **及格（D）：绩点1.5；**
- **不及格（F）：绩点0。**

因此，如果没有必须尽快补齐学分等特殊情况，通常更建议选择“缓考考试申请”，参加后续学期相同课程的期末考试。补考即使通过，也按1.5绩点记载；后续学期的期末考试则按前述课程成绩评定方式处理。
