# 贡献与纠错

本站欢迎四类反馈：指出页面错误、补充自己的学习经验、提供原始资料，以及提出撤回、匿名或隐私处理请求。内容不必先排成网页；把课程、时间、来源和仍不确定的地方说清楚即可。

## 从哪里开始

登录 GitHub 后填写下面的表单即可，不需要安装软件、编写 Markdown 或修改网页文件。只有几句话、一处纠错或一道不完整的回忆题也可以提交。

[提交资料或学习经验](submit.md?kind=material)
[纠错或补充页面](submit.md?kind=correction)
{ .resource-page-tools .contribution-choices }

“提交资料或学习经验”用于提供新材料、笔记或学习经历；“纠错或补充页面”用于指出已有页面的问题位置、原文或现象，并提供修改建议与依据。报错不需要先找到修改方法。

先从下拉框选择课程与页面，可以继续添加其他页面并逐页填写。从页面底部进入时，会自动选中当前页。新资料还没有页面时可以选择课程主页；不确定的内容照实说明即可。

**已经熟悉 GitHub 和本站结构？推荐[直接修改并提交 PR](editing.md)。** 教程包含网页编辑、同一分支修改多页、文件位置和本地预览。相关修改可以合在一个 PR 中，无需先填投稿表单。

**这里的投稿记录和附件会立即公开，尚待审核也一样。** 只提供你有权公开的内容，不要填写未公开的真实姓名、学号、成绩、课程名单、私人联系方式或群聊记录，也不要上传权限不明的原件。网页可以按你的意愿匿名，但 GitHub 账号及投稿记录仍然公开。网站是否收录会另行审核。

暂不能公开的材料，请先[通过邮件联系维护者](#contact)，只提供名称或线索，确认可以转交的范围后再发送；当前表单不是私密收件箱。想了解各类投稿需要什么信息，可以继续看下面的说明；涉及撤回或隐私时，只写页面地址和处理请求。

## 纠正内容、链接或显示问题

不知道的项目写“不清楚”，不要猜：

```text
页面或课程：
问题位置：
现在的写法或现象：
建议怎样修改：
依据：
适用的学年、学期、入学年级或班型：
时间依据：
仍不确定的地方：
```

依据可以是公开链接、通知标题、原文件名称或自己的经历。课程事实容易随学年和班次变化，发帖日期也不一定就是材料对应的学年；如果依据是考试日期、材料标题或自己的修读经历，请一并写明。

若是网页显示问题，再补充设备、浏览器、页面地址和是否开启深色模式。截图请先遮去账号、姓名、学号、成绩和聊天记录。

## 补充自己的学习经验

可以直接提供普通文字，不必套用课程主页的栏目。请说明课程名、实际修读的学年和学期，以及与内容有关的入学年级或班型；再把课程组明确要求、自己亲历的情况和个人感受分开写。只记得一部分也可以，不需要为了完整补写题目、比例或结论。

请同时说明哪些文字可以公开、是否允许整理改写，以及希望公开署名还是匿名展示。公开反馈中只填写你愿意公开的署名；如需进一步核对来源，再与维护者确认合适的非公开方式。

## 提供原始资料

回忆卷、课程通知、作业要求、课件、图片和附件应尽量保留原件。提交线索时请说明：

- 课程名和课程号，以及学年、学期、入学年级或班型；
- 学年判断依据，例如材料标题、考试日期、发帖日期或本人确认；
- 作者、原始发布者、提供或上传者、协助回忆者和整理者分别是谁；公开反馈中只写已经公开或允许公开的署名；
- 原帖或原文件在哪里，原本是公开帖子、登录后可见页面、课程群材料还是私下提供，以及图片、表格、公式、二维码和附件是否齐全；
- 希望用于哪个页面或只作核对；哪些部分可以公开，是否允许整理改写、把原文件上传到本站，以及再发到其他网站、群聊或公开项目；
- 如已取得作者或权利人的确认，说明适合公开的确认日期和方式；身份不适合公开时，只说明有核对线索；
- 已知的缺题、缺图、缺页或版本冲突。原件包含多门课程时，标出各课程对应的段落或页码，不要自行拆改原件。

不知道的项目可以写“不清楚”。旧的笼统同意、“没有看到限制”或“可以转发链接”，都不能代替这一次具体使用的确认；拿不准时先只提供线索，不要上传原件。详情见[来源与使用范围](sources-and-permissions.md)。

无权转交或明确写有“请勿传播”的原件，不要发送给维护者，只说明材料名称或页面位置与问题线索。身份或隐私证据只有在确有必要、你有权提供并已确认合适的非公开渠道时，才发送遮去无关信息后的必要部分。

## 联系维护者（非公开） { #contact }

涉及材料撤回、署名、匿名或隐私问题，可以发邮件至 [3089501757@qq.com](mailto:3089501757@qq.com)。邮件直接交给维护者，不会作为 GitHub 投稿记录公开；无需注册 GitHub。

请先说明页面地址或材料名称，以及希望怎样处理。如需进一步核对身份或来源，维护者会与你确认所需信息；不要在首次联系时附上身份证明、完整聊天记录或无权转交的原件。仍能联系原先接收材料的维护者时，也可以沿用原来的联系渠道。

## 撤回、署名与隐私请求 { #privacy }

如果你是材料的作者、提供者，或页面内容涉及你的个人信息，可以提出删除材料、移除附件、修改署名、改为匿名、遮去个人信息或更正使用范围的请求。

公开反馈中只需写明页面地址或材料标题、希望采取的处理，以及哪些信息不应继续公开；不要附上身份证明、私人聊天记录或其他敏感证据。不便公开提出的请求，可[通过邮件联系维护者](#contact)。

## 提交之后

维护者会先核对课程与学年、来源、使用范围，以及图片和附件是否完整。信息不足时先保存为待核对线索，完整与不完整的材料都可以参与补充。新旧记录有冲突时会保留原页并进一步确认，不因为投稿较新就覆盖旧学年资料。

投稿记录已经公开，但内容不会自动纳入正式网页。个人经验在允许整理时可能按读者需要合并；适用范围、署名和仍不确定的内容会保留。只允许核对的附件不会重新作为本站下载文件发布。

## 是否用于 Ginkgo 在线练习 { #ginkgo }

[ZJUBMS Ginkgo](https://yangshu233-snow.github.io/ZJUBMS-Ginkgo/) 是由 Yangshu233 开发维护的独立在线练习网站，提供选择题练习与问答卡片。投稿中适合练习的内容，可能经整理后用于该站的免费练习；原始材料与后来补充的选项、参考答案等需要区分，并保留来源。

**是否允许用于 Ginkgo，由你在 GitHub 表单的“Ginkgo 使用意愿”中单独选择。** 默认是“未同意或尚未确认”，不影响向本站投稿或在本站收录。只有明确同意后，维护者才会进一步核对来源、署名和具体使用范围；当前投稿程序不会自动把内容传给 Ginkgo。

允许本站展示文字、重新上传原附件、交给外部模型整理，以及用于 Ginkgo，是分别确认的用途。代传他人材料时，只能说明已获得的许可；范围不明确的部分留待确认。

## 是否使用 AI 整理 { #ai }

AI 辅助整理目前尚未启用。计划使用 DeepSeek、OpenAI 或 Google 的 Gemini 官方 API，帮助整理投稿、定位依据并提出小范围修改。表单默认“仅人工处理”，不同意使用外部模型不影响投稿。

提交投稿只会收件。启用 AI 后，也需由维护者先查看并批准这一版材料，才会使用你选定的服务整理本次表单文字、来源行和相关现有公开页面；生成的修改仍须人工审核后才会发布。附件和链接不会自动读取，调用失败不会转交另一家服务。

提供方的数据处理方式请查阅各自说明：[DeepSeek](https://api-docs.deepseek.com/)、[OpenAI](https://platform.openai.com/docs/guides/your-data)、[Gemini](https://ai.google.dev/gemini-api/terms)。本站不承诺这些服务默认不留存数据或不用于训练。
