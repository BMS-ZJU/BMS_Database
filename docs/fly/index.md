# 基础医学飞跃手册

2026 · 浙江大学基础医学院
{ .fly-kicker }

基础医学同学很难系统了解往届毕业生去了哪里、怎样接触科研、如何在国内直博与境外学习之间作出选择。这本手册通过采访，留下前辈的经历、选择和真实感受。

网页收录 13 份学生与毕业生访谈、4 份教师访谈。可以从熟悉的年级、研究方向或升学路径开始，按受访者阅读。

[阅读说明](preface.md) · [声明与致谢](about.md) · [项目后记](../project-afterword.md)
{ .fly-guide-links }
