# 对外交流

## 找项目与报名

对外交流项目主要从学院通知和[本科生对外交流服务平台](https://ugrs.zju.edu.cn/dwjlfwpt/main.htm)了解。学院组织的项目可能先收集报名材料、进行选拔，再办理教务系统手续；学校发布的项目按具体通知报名，并关注后续选拔和项目群消息。

部分项目会提前较长时间发布通知，可以提早留意。申请前看清面向的年级和专业、语言要求、交流时间、费用与资助条件，以及课程或第四课堂的认定要求。

## 教务系统手续

进入[本科教学管理信息服务平台（zdbk）](https://zdbk.zju.edu.cn)的“对外交流”栏目。完整图示见[本科生出国或赴港澳台申请手续办理流程及操作手册](https://ugrs.zju.edu.cn/dwjlfwpt/2020/1228/c42882a2239516/page.htm)。

### 1. 项目申请

在“交流生交流项目申请”中找到对应项目，填写信息并提交。学院另有报名表或选拔要求的，按项目通知同时完成，并留意报名和学院审核的截止时间。

### 2. 出发前办理派出手续

在“交流生交流手续办理”中查看进度，按系统要求填写信息、上传材料。**出发前完成派出手续，待“项目单位派出”审核同意后参加交流。**

可以先准备好下列材料，具体上传项目以系统及项目通知为准：

- 护照或通行证；
- 签证或签注；
- 邀请信；
- 保险单据；
- “平安留学”在线课程学习证明；
- 个人学习计划。

经费有关栏目先向负责老师确认资助来源和金额，再按要求填写。

### 3. 交流期间留存材料

保留出入境记录、往返登机牌或车票，以及学费等费用的正式票据和支付记录。需要认定课程学分的，向接收学校取得成绩单、课程大纲或相关修读证明。

订票时核对项目批准的起止时间和返程要求。项目对往返日期有要求的，即使不报销交通费，也要按要求安排；需要变更行程时先联系负责老师。

### 4. 回校办结

回国后，在系统中填写实际往返时间，补齐出入境证明、往返凭证、交流总结等回校材料，完成“回校办结”。这些材料与出发前的派出审批分属不同阶段。

“出入境交流审批申请”分为“出国(境)申请”和“回国(境)审批”，原则上分别在出国(境)前和回国(境)前填写。按实际办理经验，这两项也可以在回国后补填，用于报销。填写后，按系统提示打印相关材料，并办理相应签字、盖章。

## 回国报销

### 先确认经费和可报费用

办理前向负责老师确认项目号、授权额度、可报销的费用及材料要求。校级、院级经费是否都有资助、各是多少，以及能否同时使用，应按具体项目核定。

[2024-2025学年校级交流项目报销通知](https://ugrs.zju.edu.cn/dwjlfwpt/2025/0428/c90667a3043938/page.htm)明确，校级项目资助金额由所在院系审批确定，办理时还需核对既往及同期资助情况。

### 整理附件

先按自己要报销的费用整理票据，再对照项目和系统要求准备：

- 出入境记录，可通过支付宝搜索“出入境记录”查询并打印；
- 邀请函；
- 系统生成的审批表，以及要求签字、盖章的材料；
- 学费等费用的正式收据或发票；
- 对应的支付记录；学费支付记录按经办要求完成本人及另一位同学的签名；
- 机票、登机牌、车票等往返凭证，按所用经费和项目要求提交；
- 按要求提供的护照、身份证等复印件。

国外学校开具的 `receipt` 是收据，保留时应同时保存对应的支付凭证。“附件张数”按实际提交的材料填写；只报学费时，也要核对审批表、出入境证明等共同材料是否齐全。

票据与附件可参照本科生院公开的[海外交流报销流程](https://ugrs.zju.edu.cn/_upload/article/files/34/fa/8c8020cc42a090de9830172cd4ef/4a331551-3c1b-4efa-88b4-10b3ef41608d.pdf)，具体表名和材料要求以当前系统及项目通知为准。

### 填写报销单并交件

1. 进入浙江大学计划财务处的“网上预约报账 → 网上报账业务 → 申请报销单”。
2. 业务大类选择“因公出国（境）”，在项目号处选择老师分配并授权的项目。
3. 按票据实际支出、费用类别和核准额度填写。若学费已足以覆盖资助额度，可先确认仅报学费所需的凭证和填报方式。
4. 核对附件、签字和盖章要求，完成预约并生成报销单。医学院项目可联系综合楼801的负责老师，为报销单和出入境审批表办理盖章。
5. 按财务受理安排提交材料，留意后续退单或补材料通知。

**紫金港交件地点：**东6计财处二楼212-3，可将材料放在门口收件篮；不确定是否齐全时，可以向室内老师咨询。该交件方式最近于2025年10月核实，预约校区、时间及当次受理方式仍应在提交前确认。

## 第四课堂认定

以下依据[2023级起本科培养方案中第四课堂的修读方式与认定操作](https://ugrs.zju.edu.cn/dwjlfwpt/2025/0925/c42881a3085718/page.htm)，适用于2023级起本科生。

### 取得有效课程学分的线下境外项目

满足这类情况的同学，在“回校办结”审核通过后，可以到：

**zdbk → 对外交流 → 校外学分认定申请**

按[2025年6月更新的操作手册](https://ugrs.zju.edu.cn/_upload/article/files/43/e3/52abd68d486b995cd4d029b63521/8461fa45-d5f8-40cb-8314-ee07882a6463.pdf)，校外学分认定须在交流结束后3个月内申请。填写本人实际修读的项目、课程、学分、学时和成绩，提交证明材料，等待课程负责人及所在学院审核。审核通过后，可通过这一途径直接认定第四课堂，无需另修国际化课程。

### 其他交流情况

同一份[认定说明](https://ugrs.zju.edu.cn/dwjlfwpt/2025/0925/c42881a3085718/page.htm)还区分了其他途径：

- **线下境外项目满4周：**即使没有课程学分，也可按要求提供修读证明，在回校办结后申请“第四课堂认定”。4周按项目起止时间计算，为28天。
- **线下境外项目不足4周，且没有有效课程学分：**还需修读并通过一门学校认定的国际化课程。
- **线上交流、联合培养等其他情况：**按官方表格中的对应条目办理。

办理结束后，查看相应审核和认定结果。
